カラテで打ち合い、スリケンで追撃し、チャドーで息を整える。ナラクの力を借り、赤黒の炎で塔を焼く戦い方も。道中にはヤモト・コキやナンシー・リーなど、おなじみの顔ぶれが登場します。共に進む相手もいれば、決闘を挑む相手もいます。

専用カード、レリック、イベントに加え、キャラクターのアニメーションやアイサツ、とどめの演出を収録しています。[カード一覧](Docs/card-catalog.md)は現在、中国語のみです。

## インストール

1. [NinjaSlayer](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445)と必須Modの[RitsuLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3747602295)をサブスクライブします。
2. ゲームのMod管理画面で `STS2-RitsuLib` と `NinjaSlayer` を有効にします。
3. ニンジャスレイヤーを選んで冒険を始めてください。

ワークショップでは限定公開中のため、検索には出ません。上のリンクからアクセスしてください。対応する正式版とベータ版は、同じ配布ファイルで遊べます。

手動で導入する場合は、[GitHub Releases](https://github.com/2223M1/NinjaSlayer/releases)から共通のWorkshopパッケージをダウンロードし、ゲームの `mods` フォルダーに展開してください。RitsuLibは別途必要です。

更新前に進行中の冒険を終えてください。旧バージョンの途中セーブには対応していません。残しておきたい場合はバックアップを取ってから、新しい冒険を始めてください。

## 対応バージョンと言語

<!-- compatibility:start -->
- ゲーム正式版 `0.107.1`、ベータ版 `0.111.0`に対応。
- RitsuLib `0.5.12`以降が必要です。
- 簡体字中国語、英語、日本語のテキストを収録。ゲームの言語設定に従います。
- Windowsでテスト済みです。macOS、Linux、Steam Deckの実機確認は完了していません。
<!-- compatibility:end -->

## 不具合・感想

ゲーム内でF2を押すか、[GitHub](https://github.com/2223M1/NinjaSlayer/issues)に投稿してください。ゲームとModのバージョン、不具合が起きる直前の操作を書いていただけると助かります。

[公開統計ページ](https://2223m1.github.io/NinjaSlayer/)ではカードの統計、公開されたプレイ記録、フィードバックを確認できます。中国語・英語・日本語に切り替えられます。データ共有はMod設定で停止できます。詳しくは[プライバシーについて](Docs/privacy.md#日本語)をご覧ください。
