0.3.9 更新说明

DOMO，玩家=SAN。

- 数据站改名“忍杀情报站”，加入顶部导航、动画首屏、卡图墙、升级切换和八张新图表，保留列表、战报与来信。
- 修正多人统计单位：对局按局、生命与牌组按玩家、战斗回合数按场统计。新图表使用版本化快照，首次发布重新聚合真实数据。
- 处决时血条和状态栏留在原位；身体移动、镜头和伤害时序保持。覆盖普通多段、反向处决和建筑师退场。
- 整合最新 FMOD 事件整理与旋转攻击音频同步，保留当前问候、角色语音和事件音乐。同步剧场编排、建筑师预览和验证工具；制作工具不进入运行包。
- 更新三语说明和设置内网站按钮。本次不调整卡牌效果、模型 ID 或存档结构。
- 兼容 0.3.8 跑局；0.3.8 之前的模型 ID 仍不兼容。旧存档与历史文件不会被改写或删除。

Domo, Player-san.

- The site is now Ninja Slayer Intel, with top navigation, an animated hero, a card-art wall, upgrade toggles and eight new charts. List view, replays and letters remain available.
- Multiplayer statistics count runs per run, health and decks per player, and combat turns once per combat. Versioned chart snapshots require fresh aggregation for the first deployment.
- Health and status UI stays in place during finishers, preserving body movement, camera work and damage timing, including multi-hit, reverse and Architect finishers.
- Integrated the latest FMOD event organization and spin-attack audio synchronization, retaining current greetings, voices and event music. Theater, Architect preview and validation tools are updated and excluded from the runtime package.
- Updated three-language descriptions and the website button. No card rules, model IDs or save structure changed.
- Runs from 0.3.8 remain compatible. Model IDs from before 0.3.8 remain unsupported; existing saves and history files are not rewritten or deleted.

ドーモ、プレイヤー＝サン。

- サイトを「ニンジャ情報局」に改名。上部ナビ、アニメーション、カード絵の一覧、強化表示と8種類のグラフを追加。リスト、戦報と手紙も維持します。
- マルチプレイの集計単位を修正。冒険は1局、HPとデッキはプレイヤー、戦闘ターンは1戦ごとに数えます。初回公開では実データを再集計します。
- 処刑中もHPバーと状態表示は元の位置に固定。身体の動き、カメラ、ダメージのタイミングは維持します。連撃、逆処刑と建築家の退場にも対応。
- 最新のFMODイベント整理と回転攻撃の音声同期を統合。現在のアイサツ、ボイスとイベント音楽を維持。劇場、建築家プレビューと検証ツールは実行パッケージに含めません。
- 三言語の説明と設定のサイトボタンを更新。カード効果、モデルIDとセーブ構造は変更しません。
- 0.3.8の途中セーブに対応。0.3.8より前のモデルIDは引き続き非対応です。既存のセーブや履歴は書き換え・削除しません。
