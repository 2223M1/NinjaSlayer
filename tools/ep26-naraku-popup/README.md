# 第 26 集奈落弹出框

仅提取原片淡黄色框线与进退场色块。框内黑白脸、烟雾、黑底及框外人物、天空均透明。
不使用 ImageGen，不补画，不插帧，不改变原生 24000/1001 fps。
原框向上、向左延伸出屏幕；不凭空补出原片不可见的另两条边。
退场原有的淡黄色圆形装饰仍保留，它与黑白脸内容不同。

## 文件

- `native-rgba/0000.png .. 0144.png`：145 张 1920×1080 原生节奏 RGBA，约 6.0477 秒。
- `alpha/`、`core/`、`edge-band/`：逐帧审计蒙版。
- `hold.png`：稳定停留框，内部透明，源坐标不变。
- `runtime-atlas.png`、`animation.json`：入场 5 帧、停留 1 张、退场 4 帧，带每格裁切原点；显示时不跳位置。
- `empty.png`：退出后的完全透明状态。
- `preview-2s-hold.mp4`：棋盘格背景演示，不是带透明度的生产视频。
- `frame-ledger.json`、`manifest.json`、`audit.json`：原帧定位、SHA-256、方法与审计。

## 自定义时长

停留时长与进退场速度独立。进入固定 5/23.976 秒（约 0.209 秒），退出固定 4/23.976 秒（约 0.167 秒）。
`hold_seconds=2` 时总时长约 2.3754 秒；原片停留时间为 136/23.976 秒（约 5.6723 秒）。
不要把整个视频变速来延长停留。

附带 Godot 4 示例 `popup_player.gd`：挂到 Node2D，资源保留同目录。
`play(2.0)` 停留两秒后退出；`play(-1.0)` 一直停留，调用 `close()` 后播放原生退场。
原生设计画布为 1920×1080，Node2D 在画布左上角，后续整体设置 position/scale。
此素材未接入任何实际游戏行为，也未写入游戏安装目录。
PNG 图集保留真实 Alpha；OGV 无 Alpha，不作为透明交付格式。

## 重建与审计

源 PNG 在构建目录的 `source/`，对应 ffmpeg 从第 26 集 346.75 秒开始按原生帧率提取 7 秒。
`build_popup.py build` 重新生成 RGBA 和图集，`verify_popup.py` 重新读取源 PNG 独立检查。
完整文件路径、视频哈希、原帧号和实际 PTS 位于 manifest/ledger。
不透明 Core RGB 逐字节来自原帧；仅保存的 3px Edge-band 内执行双颜色 Alpha 求解和背景反混色。
边缘颜色反混色是确定性图像处理，不宣称边缘 RGB 与原始合成背景逐字节相同。
