# 单人不歪种

以猫粮杯竞速比赛专用 Mod（CFCRacingMod）1.1.2 的单人随机规则为行为基准，仅在真正的单人忍者杀手局启用。原版角色、一人联机房间、联机房主／客户端及多人局均不启用。没有设置开关，不包含计时器、海选、固定路线、统计或快捷操作。

如果原版 CFCRacingMod 已用其 `CFCRacingMod` Harmony 所有者安装遗物稀有度补丁，整组规则让原 Mod 处理，避免两次改种和重复计数。

## 规则边界

沿用原生随机数类和生成接口；只更换猫粮杯实际修改的随机流。各计数按原版猫粮杯的**回调次数**累计，不按地图坐标去重。恢复父事件会再次计入事件／先古次数。Boss 洗牌只依赖遭遇 ID 的确定性散列，与运行种子无关。这些行为刻意保留，不额外修正猫粮杯的策略。

| 入口 | 种子／行为 |
|---|---|
| 进入房间 | 奖励流为运行种子加普通／精英／Boss／商店对应计数乘 5280／5281／5282／5283；其他房间使用普通计数。重置房内卡牌索引和首次稀有度标记。 |
| 战斗洗牌 | 普通／精英分别乘 5280／5281；Boss 使用遭遇 ID 散列，并赋回原生运行洗牌流。 |
| 生成敌人 | 运行种子加对应战斗计数和遭遇 ID 散列；非三类战斗使用事件计数。 |
| 生成卡牌 | 运行种子加（对应房间／事件／先古计数＋房内生成索引）乘 5284；每次生成选项递增索引。 |
| 卡牌奖励 | 普通／精英／Boss／商店／事件／先古使用对应计数乘 2580／2581／2582／2583／2584／2585，再加运行种子和本组卡牌奖励索引；重掷再加 1290。保留原生选项对象可能共享的行为。 |
| 卡牌稀有度 | 普通、精英、Boss、商店分别维护保底；金卡后 -0.05，其余按原生增长率增加，最高 0.4。先古入口全部置 -0.05。每房间第一次稀有度投掷以运行种子加对应计数乘 8520／8521／8522／8523 重置底层随机流。 |
| 药水掉落 | 本地玩家种子＋掉落调用次数×8520＋2580；沿用原生掉落概率。 |
| 药水生成 | 本地玩家种子＋生成批次数×8521＋2580；一次原生批次只增加一次计数。 |
| 遗物稀有度 | 开局使用命名流 `RelicRarityRng` 预生成 400 项，阈值为原猫粮杯的 0.5／0.83，依次消耗，不消耗调用方随机流。用尽后不另造延长序列或回退规则。 |

战斗计数在 `CombatRoom.OfferRoomEndRewards` 前增加，事件／商店在各自 `EnterInternal` 前增加。目标选择、敌方 AI、武器手部等其他随机流不单独改种。

## 保存与维护

`SingleplayerSeedRules` 用 RitsuLib 的运行数据保存计数、四类保底及剩余遗物序列，键为 `cfc_singleplayer_rng`。房内生成索引和首次重置标记不保存，由房间入口重新建立。不为更新前的运行存档重建历史；请使用新局。

入口补丁位于 `SingleplayerSeedPatches.cs`、`SingleplayerRewardSeedPatches.cs`，共 14 个补丁类、17 个精确宿主目标，接入既有必需补丁事务。没有额外随机管理器、扫描或网络协议。stable 的原生 RNG 接受 32 位种子，preview 接受 64 位种子；在功能内编译分支处理，不声称两个宿主会产生相同牌序。

验证与参考 DLL 指纹见 [本轮验证记录](validation/singleplayer-seeds-20260926.md)。
