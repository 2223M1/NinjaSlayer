# 一心同体与手里剑生成调整验证 · 2026-11-09

基于 `3d4c2776ebb98928795208d938f6e21aac46057e` 的本地工作区，包含此前未发布的浴火调整。本次未提交、安装到日常游戏或上传 Workshop。

## 最终规则

- 一心同体保持3费、能力、虚无，每次打出获得5→8点奈落生命，并增加1层换算倍率。
- 空手道攻击触发伤害、图标数字与说明数值为「实际空手道＋奈落生命×一心同体层数」。奈落生命和倍率变化时同步更新。
- 每波空手道触发优先消耗1点奈落生命，倍率不增加消耗；没有奈落生命时才失去1层实际空手道。群攻一波消耗一次，多段分别消耗。
- 一层形态、5层基础空手道与5点奈落生命，触发伤害10，随后显示9。两层形态下，同样资源触发伤害15，随后显示13。两个例子均保留5层实际空手道。
- 实际空手道不会抵挡伤害。阿拉巴马落、倍劲、坚壁及对应生成组件继续读取实际空手道。
- 多段血条与处决预览分别模拟奈落生命和实际空手道的递减，缓存区分基础层数、生命和换算倍率。
- 手里剑生成移除预见、相关变量与悬停说明，保持1费、奇巧、获得3→4层手里剑；AutoAnthony组件同步移除预见。
- 16种语言、卡牌目录与数值基线均已同步。

## 原版接口证据

检查 active stable 0.107.1 与 preview 0.111.0 的对应导出。

- `Core/Models/PowerModel.cs`：`Amount`保存真实层数；`DisplayAmount`提供显示值；动态变量参与能力说明格式化。
- `Core/Nodes/Combat/NPower.cs`：`RefreshAmount`读取可变能力实例的`DisplayAmount`，监听`DisplayAmountChanged`刷新。
- `Core/Commands/PowerCmd.cs`：应用/改变层数会调用对应钩子，归零移除能力；战斗结束时普通修改命令拒绝执行，因此保留最后一波的消费处理。
- `Core/Models/Powers/ThornsPower.cs`：荆棘在`BeforeDamageReceived`先反伤，可先消耗奈落生命。当处决预览遇到这个组合时返回无法保证击杀，避免提前播放处决；实际空手道按反伤后的生命结算。
