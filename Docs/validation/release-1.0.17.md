# 1.0.17 独立反馈界面与遥测文案

基于 1.0.16，按作者提供的简体中文原文更新遥测首次提示、数据分享说明和公开战报说明，并同步 16 种已支持语言。设置页只显示开启／关闭，删除待定状态文字；首次提示关闭后下次启动默认开启、明确拒绝持续停用、公开战报独立授权的实际逻辑保持不变。

局内本机忍者杀手 F2 和首次标准模式胜利使用同一独立模组表单，复用 RitsuLib 设置 Shell 的面板、文本与按钮，不创建或打开原版反馈表单。通过原生模态容器管理活动界面，打开时屏蔽下层快捷键，关闭时释放并恢复焦点；其他角色、主菜单的原版反馈入口不变。

删除共享原版表单的四个 Patch、表单改色恢复类、全局确认会话和仅为原版共享发送路径服务的流所有权包装器；发送按钮直接调用模组反馈客户端，用自己的 using 作用域持有附件，不再要求二次确认。公开文字、私有截图／日志及接收方说明放在表单内。保留类别、8000 字限制、截图和日志、服务回执、失败重试；关闭后仍进行的上传不会写入新打开的表单。附件的非关闭包装仍用于 HTTP 重试，避免请求销毁提前关闭原始流。

卡牌、模型 ID、奖励池、初始卡组、跑局存档和遥测请求 ID 均未改变，因此卡牌目录无需修改。公开战报保留期和采集边界不因说明文案缩短而改变。未部署 Worker，不创建 GitHub Release。

## 验证与发布

本轮发布必须通过本地逻辑／仓库／构建边界检查、两宿主产品与 Patch 契约、16 语言资源验证，并以隔离后台桌面的原生首通和 F2 单击发送实测确认独立表单与回执。测试上传仅指向本机 loopback，不提交真实反馈或触碰日常存档。

最终提交、检查结果、实际执行平台与 Workshop 下载文件散列将在发布完成后写入相邻精简证据。
