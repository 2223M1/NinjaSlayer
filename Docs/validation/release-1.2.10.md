# 1.2.10 创意工坊发布记录

[Steam 工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445)已发布 1.2.10。残心基础和升级均为 0 费，每次触发抽 1 张，升级获得固有。修复了联机中暗打触发回避时的不同步，以及黑炎与空手道同时触发、击败最后一批敌人时漏播处决动画的问题。

Steam 回下载的 11 个文件与冻结候选包的路径、大小和 SHA-256 均一致，内容 manifest 为 `7231541697442752113`。正式版 0.111.1、预览版 0.113.1 分别通过 180 和 185 组玩法回归，两版均验证了双进程联机回避、残心和黑炎处决。另有 367 项独立逻辑测试通过。见[发布与校验证据](release-1.2.10-evidence.json)。

[本次 Steam 公告](https://steamcommunity.com/sharedfiles/filedetails/changelog/3776911445/#1795016293)的 16 个独立语言栏均已保存并重载，逐条与发布文本核对，无语言回退。见[各语言回读记录](workshop-1.2.10-notes.json)。[Discord 四语草稿](discord-1.2.10-drafts.md)已准备；整理记录时 Discord 要求重新登录，尚未发送。
