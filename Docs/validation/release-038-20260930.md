# 0.3.8 卡牌、模型命名与演出验证

## 范围与基线

实现基线为已发布 0.3.7 `50777823e631af16690258520847aef984ffc1c7`。本轮修改包括 v1.17 编辑板的已确认规则、黑暗忍者循环与黑暗反击、阵营中心死斩、敌方鞠躬方向、建筑师最终继续后的互礼、巴投落地反馈及两种入场动作。详细模型对照见 [模型 ID 对照](../model-ids-0.3.8.md)。

93 张卡、20/35/25 奖励池及初始卡组保持。撒菱使用原生永久荆棘，删除专属到期 Power。三语文本、当前规格、直接资源引用与东尼可选程序集同步。全部 93 张卡图内容与基线逐一核对，重命名不替换图像。

中英文模型名与两个支持宿主的原版本地化核对；基础打击/防御及手里剑球按用户确认豁免。预见关键词仍为 Scry；原预判改为料敌 / Read Ahead，原引火改为燃火 / Kindle。手里剑球仍为手里剑 / Shuriken，`ShurikenOrb`、原模型 ID 及场景路径保持。

旧模型不注册别名、不迁移旧跑局。旧存档及历史文件不改写、不删除。本轮不修改网站、快速出牌器或外置制作工具，不创建 GitHub Release。

## 测试修正与限制

- stable 的建筑师自动测试最初误在第一幕进入事件，原版继续会推进下一幕；测试改为最终幕并等待原生异步胜利计数，再断言只增加一次。没有据此修改宿主胜利逻辑。
- 额外 FirstCombatRestart 检查发现两条旧断言：基础备镖仍预期两层、随后地狱龙卷倍增预期四层。按本轮一层/倍增两层修正测试后完整重跑通过。两次失败不计作产品通过。
- 游戏退出记录仍含 Godot 资源/RID 泄漏与信号断开诊断；本轮未证明其来源，不声称零错误或已修复这些诊断。
- 未完整执行四客户端渲染、所有镜像/暂停/跳过/药水兼容排列、黑暗忍者每个行动位置的实际战斗存档 SL、所有死亡/闪避排列。原生状态恢复契约不替代实际 SL。
