## 已发布内容

- 备镖改名为戒备（On Guard），韧性及对应能力改名为转机（Turning Point），同步16种语言、东尼算法和卡牌目录。连打与破势一击沿用已确定的名称。
- 11项卡牌调整、7项机制与显示修复、61张卡图替换已一并发布。完整的25条更新说明固定于 `Workshop/change-note.md`，与 `Workshop/workshop.json` 的 changeNote 及工坊最新更新记录一致。
- 鲔鱼寿司由拾起时回复所有生命，改为从牌组选择3张可附魔的牌，附魔滋养1。每张牌每场战斗首次打出时增加1点最大生命，按原版提升上限规则回复相应生命；同张牌回手重打不重复触发。可选牌不足3张时沿用原版选择命令处理，已有附魔和不可打出等限制遵循原版规则。16语言遗物描述及附魔提示已从最终包渲染验证。
- 沢渡仍仅替换强敌阶段的问号战斗。出率使用本局实际生成或载入的完整事件队列，包括共享事件、原版解锁过滤，并排除已访问及当前不符合条件的事件；将沢渡计作额外一个等权事件槽位。事件概率按宿主最终允许的房间类型计算，仍受可替换战斗概率上限约束。教程、弱敌阶段、已遇到沢渡的跑局不触发。小季、鸟居、奈落、京都事件保持标准注册与原生事件队列。
