# 1.2.10 Discord 公告草稿

## Ninja Slayer 1.2.10 — 中文
https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445
• 残心由 1 费降至 0 费，触发时的抽牌数由 1→2 张改为固定 1 张，升级获得固有。
• 修复了用户反馈中暗打触发回避不同步的问题。
• 修复了用户反馈中黑炎清场漏播处决的问题。

## Ninja Slayer 1.2.10 — 日本語
https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445
• ザンシンのコストを1から0に変更。発動時に引くカードは1→2枚から一律1枚になり、アップグレードで天賦が付くようになりました。
• ダーク・ウチに対して回避が発動すると、マルチプレイで同期がずれることがある不具合を修正しました。
• 黒い炎で残りの敵をすべて倒した際、処刑演出が再生されない不具合を修正しました。

## Ninja Slayer 1.2.10 — 한국어
https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445
• 잔심의 비용이 1에서 0으로 감소합니다. 발동할 때 뽑는 카드는 1→2장에서 1장으로 고정되며, 강화하면 선천성을 얻습니다.
• 암흑 타격에 회피가 발동하면 멀티플레이에서 동기화가 어긋날 수 있던 문제를 수정했습니다.
• 검은 불꽃으로 남은 적을 모두 처치했을 때 처형 연출이 재생되지 않던 문제를 수정했습니다.

## Ninja Slayer 1.2.10 — English
https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445
• Zanshin now costs 0 instead of 1. It draws 1 card per trigger instead of 1→2. Upgrading it adds Innate.
• Fixed a reported multiplayer desync when Evasion triggered against Dark Strike.
• Fixed a reported issue where clearing the fight with Black Flame skipped the finisher animation.
