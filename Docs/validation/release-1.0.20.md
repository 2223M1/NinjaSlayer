# 1.0.20 新反馈与演出兼容修复

逐条核验1.0.19之后的官网公开反馈，结论及附件散列见 [feedback-1.0.20.md](feedback-1.0.20.md) 与同名JSON。纯强度、内容建议不改平衡；龙卷反馈缺少可用两端状态，保持未解决。1.0.20已发布，最终文件散列、CI和实机结果见 [release-1.0.20-evidence.json](release-1.0.20-evidence.json)。

## 根因与修改

- 手里剑崩溃：猪煲Q版0.1.5的全局充能球工厂前缀错误抢占手里剑，尝试加载不存在的原生路径。仅手里剑专用初始化使用RitsuLib公开 `IModOrbSpriteFactory.TryCreateOrbSprite()`；保留原生NOrb更新，不识别第三方ID、不改第三方、不吞异常。
- 角色右漂：Litter the Spire 0.3.0连续调用原生 `CreatureCmd.TriggerAnim(Attack,.1)` 暴露本模组独立攻击路径的累积位移。旧包在干净环境连续12次触发也右漂约359.867px。删除独立的根节点Tween和收尾，复用已有视觉位移与收招接管；新动作先完成上一动作归位，再取得基线。
- 黑炎联机死亡：死亡玩家的牌堆被原版移除，战斗仍为其他玩家继续；已排队的回合末黑炎仍被调用。死亡者不再启动这次黑炎结算，活人缺失战斗状态仍抛错。保留原生死亡、牌堆与动作流程。此异常来自龙卷反馈附件，但不能证明龙卷主诉同根因。
- 手里剑层级：去除场景子节点和标签的额外ZIndex，沿用原版充能球相对Z=0及节点顺序；仍在Visuals下的手持砍刀之上，卡堆界面可正常覆盖。没有增加顶层画布或专用UI排序系统。
- 沙虫与小季：原版SandpitPower在沙虫身上，Target为玩家；由原生钩子移动玩家和宠物。新增/移除小季纸飞机触发的绝对站位重排，以及沙坑生效前排队的重排动画，都会覆盖右拉位置。沙坑控制队伍时停止本模组的绝对重排和待执行位移动画。原生AddCreature还会将已有宠物重新放到玩家身旁，因此在该调用期间保留受沙坑控制的本模组同伴位置，随后由原生Sandpit新增生物钩子移动整个队伍。玩家和小季均实际向右移动，保持原相对站位；不重写沙坑算法或新增存档状态。

## 验证与边界

四项明确缺陷（黑炎、竞争充能球工厂、连续攻击漂移、待执行重排覆盖沙坑）均保留旧1.0.19失败基线和新候选通过证据。手里剑层级另有资源/标签契约。完整stable 0.107.1与preview 0.111.0程序集用于构建和行为验证。

实机额外保留同伴间距失败基线：仅停用绝对重排后，新增纸飞机仍将小季从玩家左侧291.204像素排到右侧75.204像素。补齐AddCreature边界后，三速度两人共同右移267.648像素且间距保持291.204像素。

旧阿拉巴马网格观察器把无独立head插槽的图集全部隐藏，帧回调的异常只进入Godot日志，最终默认零误差不能证明网格接地。测试现区分独立头部与完整身体冠顶，要求实际网格采样数大于零，并将帧观察异常传回测试主流程；最终证据记录网格类型与有效采样数。此前文档中只依赖旧观察器的逐帧头部网格结论不作为本轮发布依据。

双进程原生ENet新增双方分别执行X=4/20/60龙卷的回归，逐次比对生命、格挡、能力、能量与随机数状态；两个宿主均未失步。反馈中的移动端嵌套失步ZIP已被原生 `GetLogsConsoleCmd.ArchiveLogFile` 当UTF-8文本重写，包含大量替换字符，无法还原完整远端状态。不能据桌面契约通过宣称移动端龙卷已修复，不改变龙卷玩法代码。

实机测试沿用后台隔离Windows预览客户端，先只加载NinjaSlayer与RitsuLib，再对照加载Litter the Spire 0.3.0或猪煲Q版0.2.7。后者是当前可取得版本，不等同报告中的0.1.5。未测试完整stable客户端、Android、macOS/Linux或两个完整渲染客户端；这些范围不得写为已通过。

没有更改随机序列、消费顺序、内容标识、资源路径、存档键和对外API；不新增全局兼容框架、第三方私有依赖、历史档猜测修复或默认值回退。

## 工坊发布回验

2026-10-10（UTC+8）发布1.0.20，产品提交为 `a05f13fb2cf07aaf85e3514b81201938533881f2`（[PR #200](https://github.com/2223M1/NinjaSlayer/pull/200)）。该提交的 [main CI](https://github.com/2223M1/NinjaSlayer/actions/runs/37963918890) 通过；基于同一提交冻结的统一包完成双宿主产品契约、Patch安装／回滚与双进程原生ENet验证。371项逻辑测试、仓库、本地化和兼容配置检查均通过。

最终统一包在完整Windows预览客户端完成五项隔离实机验证：仅NinjaSlayer与RitsuLib的FeedbackCombat、MultiHitVigor、Catalog，以及分别与Litter the Spire 0.3.0、猪煲Q版0.2.7共存的FeedbackCombat。普通、快速、瞬间模式下，忍者杀手与小季共同右移267.648像素，新增及移除纸飞机前后相对X间距均为291.204像素。手里剑仍在沢渡砍刀上方，卡堆界面正确覆盖。修正后的Mawler完整身体冠顶观察器每种速度取得约15个有效阿拉巴马网格样本，压缩落地接触误差约0.000061像素。

实机卸载阶段仍有既存Godot GC handle和RitsuLib访问已释放贴图的日志；本轮明确断言通过不代表零错误日志。完整stable客户端、移动端及其他平台的边界保持如上，不将当前猪煲0.2.7共存结果表述为历史0.1.5实机通过。
