# 1.0.22 攻击收招与杀气·直气文案

2026-10-11 发布，产品提交为 `9233a89dd6884859aa9e90999ab5d217e45180d0`（[PR #205](https://github.com/2223M1/NinjaSlayer/pull/205)），[产品提交 CI](https://github.com/2223M1/NinjaSlayer/actions/runs/38117595178) 通过。

## 改动

| 模式 | 普通攻击收招 | 重击收招 |
| --- | --- | --- |
| 普通 | 0.5 秒 | 0.7 秒 |
| 快速 | 0.3 秒 | 0.5 秒 |
| 瞬间 | 立即复位 | 立即复位 |

这些时长控制结算后的实际位移与姿态回收，普通攻击、独立触发和对应处决动作共用设置。前摇、伤害等待、多段之间的回位和下一动作接管不变，居合、翻滚、腾空与龙卷仍使用自己的编排。

杀气·直气卡牌说明改为“获得9点格挡。在敌方回合结束时，若你格挡了所有攻击伤害，对攻击者造成47点伤害。”16 种语言的卡牌及能力说明同步简化，保留 `{Block:diff()}`、`{Damage:diff()}` 和能力的 `{Amount}`。升级仍为 12 格挡／56 伤害，反击时点、目标与修正结算保持原行为。

## 验证与发布回验

同一提交重新导出资源并构建 stable 0.107.1／preview 0.111.0 两套实现，冻结为统一工坊包。两宿主完整产品契约、Patch 安装与回滚、双进程原生 ENet 均通过；既有 AutoAnthony 公共接口组件契约通过。源提交的 371 项逻辑测试、仓库、本地化与最终 CI 检查通过。

隔离后台预览客户端验证普通／快速／瞬间速度下的基础及升级攻击，共 42 项多段攻击用例、8 项结算后的真实收招观测；Godot 契约按新时长验证位移半程、归位与姿态恢复。运行时目录确认基础版 9／47、升级版 12／56 的文字、动态值与升级颜色正确。未运行完整 stable 客户端、Android/macOS/Linux 或两台完整渲染联机客户端。

更新既有[工坊条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445)，重新下载的 12 个文件长度和 SHA-256 与冻结包全部一致。固定更新说明“我们修复了一些问题，增添了一些内容，调整了一些东西。”已回读确认；16 语言标题及介绍、标签、封面、画廊、依赖和公开状态保持一致。

官网目录从已回验的下载包再次导出，保留历史目录。未修改反馈状态，未创建 GitHub Release。构建来源、文件散列、测试范围和目录指纹见 [release-1.0.22-evidence.json](release-1.0.22-evidence.json)。
