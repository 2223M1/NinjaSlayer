## 射箭结论修正

用户补充：没有亲自确认实机重复扣血，看到的是其他对话生成的剧场预览射了两次。旧 `yukano-popup-normal.json` 明确安排 `first_arrow`、`second_arrow` 两次行动，fast 脚本也有重复行动测试，不能据此认定产品单次射箭重复伤害。

已发布基线与候选在首次弹窗、普通射箭、快速模式、暂停恢复、放箭前及放箭后故障回退六种实机场景均为一次投射物创建、一次主伤害。处决中的最后 1 HP 死亡提交单独记录，不算第二次攻击。因此本轮不宣称修复了已证实的重复扣血故障。

保留计划授权的单一归属调整：影片仅通知放箭时点，动作统一创建并等待投射物；正常影片和故障回退汇入同一创建位置。影片结束后不会补发。新增单箭展示脚本 `yukano-popup-single.json`，本轮未生成新视频。

候选另测放箭前取消、目标失效：均无投射物、无主伤害，行动可结束。失效场景由测试将目标生命置零触发原有检查；不宣称覆盖所有中途死亡来源。首发日志中影片放箭窗口与投射物创建在同一渲染帧；伤害在飞行等待结束后，未额外捕获画面测量命中像素。

## 处决修复证据

三处前向预判（玩家、友军/远程、小季预规划）统一检查原生 `Hook.ShouldStopCombatFromEnding`，原生要求继续战斗时不暂留末点生命。中间阶段由原生伤害、死亡及召唤处理；最终阶段保留原有处决。没有新增怪物名单、存档字段或全局管理器。

使用真实 `PhrogParasiteElite`、`AxebotsNormal`、`GremlinMercNormal` 遭遇；各测随机多段（升级掌打）、群体多段（升级小刀喷射）、固定目标（升级双重打击）。

| 对照 | 结果 |
| --- | --- |
| 已发布 0.3.3，异蛙随机多段 | 三段均命中异蛙父实体，启动一次处决；测试明确失败 |
| 候选，异蛙随机多段 | 第一段异蛙，后两段 Wriggler；中间阶段不处决 |
| 候选，三种怪物 × 三种选敌 | 九组通过；父实体仅承受致死段，随机/群体沿用原生后续目标，固定目标不转移 |
| 候选，最终敌人 | 仍正常进入一次最终处决 |

Axebot 后续实体与父实体模型 ID 相同，断言使用实体引用区分，不以模型名冒充重选目标。测试没有覆盖九组的全部原版角色对照；原生目标和召唤规则由宿主命令直接执行。
