正式版 release_info 记录 commit `cc1f9462`，DLL SHA-256 为 `3fb1fa1bf0249087b706a5d0f062a60579e2f5b08df4ee477ddd6f2607f654d5`。新版本使用 RitsuLib 的 0.111.0 ABI；这不意味着模组兼容旧游戏 0.111.0。两个分支均按 0.6.13 NuGet 基线编译，并使用本机创意工坊的 0.6.14 运行库验证。直接调用该运行库的装载器确认其分别选择 0.111.0、0.113.0 的五个模块。模组自身的加载器只接受表中两个精确游戏版本。

GDRE 2.7.4 将完整正式版工程恢复到相邻源码库的 `Slay the Spire 2 v0.111.1`。恢复 3,591 个脚本，另外 7 个脚本无法反编译；4,029 份导入资源均转换成功（其中 1,253 份为有损转换）。原版建筑师骨骼的 SHA-256 与模组正式版处决素材来源一致。检查目录、链接、工作树及活动进程后，移除了 0.107.1 冗余源码（19,263 个文件，1,278,633,635 字节），保留其恢复日志，SHA-256 为 `988aec4b95e0f7b13a800070046ab9a46248b78aa31829015d11c4a8215ff165`。共享工具和其他模组未清理。
