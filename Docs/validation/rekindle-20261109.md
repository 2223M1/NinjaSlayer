# 浴火调整验证 · 2026-11-09

本地未发布修改，基于 `3d4c2776ebb98928795208d938f6e21aac46057e` 的工作区；不是已发布 1.2.0 的验证记录。

## 当前效果

1费技能，消耗。

> 选择你手牌中的一张牌，将其变化为黑炎。
> 本回合内，每当你触发黑炎时，获得2→3点奈落生命。

- 沿用原有 `CardSelectCmd.FromHand` 和 `CardCmd.TransformTo<BlackFlame>`。
- 在黑炎共同伤害入口给予奈落生命，移除浴火原来的技能牌监听。
- 手牌攻击触发、回合结束触发、奈落形态触发均计入；一次触发只获得一次，不按敌人数或攻击段数计数。
- 回合结束触发时，先获得奈落生命，再结算伤害，因此可以抵挡当次黑炎自伤。
- 生成或变化为黑炎本身不提供奈落生命。浴火叠加其收益数值，仅作用于持有者，在其回合结束后移除。
- 同步16种语言的卡牌与能力描述、AutoAnthony组件描述、卡牌目录和数值基线。

## 原版对照

- `0.111.0/localization/zhs/cards.json` 的 `BEGONE.description` 使用“选择你手牌中的一张牌，将其变化为……”句式。
- `0.107.1` 与 `0.111.0` 源码的 `Core/Combat/CombatManager.cs`，`EndPlayerTurnPhaseTwoInternal` 均先等待 `FlushPlayerHand` 完成，再调用 `AfterTurnEnd` / `AfterSideTurnEnd`。浴火沿用现有 RitsuLib 回合结束接口，覆盖黑炎回合结束结算后才失效。
