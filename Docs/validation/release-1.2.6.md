# 1.2.6 发布记录

[Workshop 条目 3776911445](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445) 已上传并回下载验证为 **1.2.6**。产品源码冻结于 `9b8f0820025667c34cfd91b3f6a374c497ebf273`，Steam 内容 manifest 为 `1822347320104142370`。

## 改动

- 烈焰基础费用由 1 费降为 0 费，升级后保持 0 费并获得固有。
- 从容新增虚无，升级由获得固有改为移除虚无；费用和弃牌获得格挡的效果不变。
- 模组的“瞄准”更名为“标靶”，同步 16 种语言，保留序列化 ID、精准图标和既有机制。“标靶”是功能性设计命名，不作为原著专有名词。
- 破势一击给予的标靶由 2→3 层提高至 3→4 层，伤害仍为 6→9。

## 验证

- 正式版 0.107.1 和测试版 0.113.0 独立构建及通用工坊包构建通过，使用实际工坊 RitsuLib 0.6.11 运行库。
- 两版完整玩法契约分别通过 165、166 个检查组，包含 93 张卡基础／升级元数据、标靶增伤、强手里剑、与易伤乘算、优先攻击、持续回合及人工制品。两版补丁安装、故障注入和回滚契约通过。
- 367 项逻辑测试通过；网站与 Worker 测试 82 项通过，1 项因缺少额外遥测样本跳过。仓库、兼容配置、16 语言网站文案及工坊更新说明传输检查通过。
- 同一正式 DLL 单独导出 16 语言、1860 个模型的官网目录。逐语言核对烈焰 0／0 费和升级固有、从容基础虚无和升级移除、破势一击的新名称及 3／4 层显示。
- 回下载的 11 个文件路径、大小、SHA-256 与冻结包全部一致。四行更新说明逐字一致；工坊公开状态、依赖、预览图、标签及 16 语言标题／介绍保持原值。
- 官网目录推进至已验证的 1.2.6；本次包含卡牌规则改动，使用独立的 1.2.6 统计分组。
