# 龙·飞踢结算顺序与官网多版本统计

基线 `884b6bbd1f610f510d64fa6819c623deba528367`，接续 1.0.7 的多段活力、巴投／皇帝蟹修复。此记录区分提交前候选和最终发布；最终源码、文件校验值及下载结果另见 `release-1.0.7-evidence.json`。

## 实现

- 龙·飞踢仍先造成伤害，随后茶道呼吸，最后按此时的手牌空位抽牌。伤害、费用、呼吸次数、消耗和模型 ID 不变；同步中英日描述和卡牌目录。
- 无茶道时先生成茶道占用一个手牌位；已有茶道先得到呼吸收益。本次随后抽到的茶道不追溯获得收益。
- 官网版本筛选支持任意多个勾选，未选时统计全部版本；URL 使用重复 `version` 参数，刷新、三语切换保留选择，旧单版本链接继续有效。
- 卡牌、趋势、八张图表、战报、本机统计与 CSV 使用同一选择。按实际计数合并后计算比率，不平均各版本胜率；重复选择不重复计数。快速连续勾选时，仅最新请求可以更新页面。
- 奈落生命联机黑屏报告尚无双方日志，用户明确要求先继续发布其他内容。本次未修改奈落生命，不宣称解决该报告。

## 提交前验证

- 新龙·飞踢契约在旧 DLL 上失败：先抽入牌堆中的茶道后才呼吸，未生成预期的新茶道。调整后 stable 0.107.1、preview 0.111.0 完整 DLL 契约通过，覆盖基础／升级、有／无手中茶道、抽满手牌、新抽茶道仍为 1 能量、原牌消耗及原伤害。
- 双宿主产品、SmokeDriver、通用包构建与包边界通过。候选源码为基线加本次差异，未冒充干净最终提交。
- 本机 preview 隔离后台桌面从通用根加载器运行，五张多段牌 20 次行动及龙·飞踢基础／升级×有／无茶道×Normal／Fast 共 8 组通过。未改日常安装。
- 375 项逻辑测试通过；网站／后台／Worker 73 项通过、1 项既有测试因未提供专用遥测夹具而跳过。
- 多版本测试覆盖 12 个可选版本、非连续子集、重复选项、空选择、无数据版本、其他条件交集、联机去重、不同版本样本量的胜率权重及本机 API 重复参数；公开聚合与私有统计一致。
- Chrome 无头浏览器实测中文 1440px、英文／日文 390px：多选、取消选择、键盘操作、重置、旧链接、刷新恢复、八张图表与战报筛选、无横向溢出和无脚本错误。未截图或录屏。
- 仓库一致性、兼容清单、构建边界通过。Godot 契约有既有退出释放警告，不记作无警告运行。

最终发布前重新从干净合并提交构建，运行通用根加载器首战／重启、多段活力、巴投及新增龙·飞踢实机回归。独立多人客户端、macOS／Linux 和奈落黑屏复现不在已通过项中。
