# 1.2.2 发布记录

已上传并重新下载验证 [Workshop 条目 3776911445](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445)。产品源码冻结于 `6aedbb9dd389e5593b2a792d8fded440e78dde46`，正式包版本为 **1.2.2**。

## 已发布内容

- 沢渡事件支持没有 FadeIn 的快速 SL 入口，正常继续仍等待淡入；重复及过期回调不会重复开战。
- Boss 问候延迟音乐时同时保留最新进度参数，在新曲目启动后应用，退出战斗时撤销待播内容。
- 帝皇蟹从共享背景骨架捕获死亡碎片，第一只钳子死亡保持原版动作，最后一只死亡爆炸，同时击杀只生成一次。
- 交叉防御跳过能力牌，保留效果直到下一张非能力牌回手；16语言说明同步。
- 修复被牌堆切换中断的重复出牌淡出，并隔离仍在飞行动画中的能力牌节点，避免卡牌保留透明状态。用户忘记的具体牌无法从日志确定，本次针对已复现路径修复。
- 阿拉巴马落实际驱动选中钳子的原版骨骼，支持抬升、翻转、摔落、存活复位和死亡交接，另一只钳子及主体不随之位移。

发布的六行说明与冻结源码中的 `Workshop/change-note.md` 和 `Workshop/workshop.json.changeNote` 一致。未改写旧版更新记录。

## 验证

- stable 0.107.1、preview 0.111.0 正式包构建通过，零警告、零错误；完整玩法、反馈专项和补丁安装／故障注入／回滚契约均通过。
- 367项逻辑测试通过，无失败、无跳过。反馈契约涵盖快速SL、音乐调用次序、连续能力牌保留交叉防御、真实原版淡出 Tween 中断，以及帝皇蟹共享 Spine 捕获和两只钳子的完整阿拉巴马落流程。
- 正式包在后台桌面以 OpenGL 和 RTX 5080 完成图形契约，已查看真实钳子移动截图及碎片图集。普通复位、死亡前交接和离树清理通过。
- Steam 回下载的全部12个文件，路径、大小和 SHA-256 与冻结包完全一致。16语言标题／描述、依赖、可见性、预览图及忽略大小写后的标签集合保持不变。
