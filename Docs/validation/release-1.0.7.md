# NinjaSlayer 1.0.7

运行包源码：`7e04386fd7e2fd3e698d2117a150a0a2f0a92c7e`。GitHub PR [#165](https://github.com/2223M1/NinjaSlayer/pull/165)、[#166](https://github.com/2223M1/NinjaSlayer/pull/166)、[#167](https://github.com/2223M1/NinjaSlayer/pull/167) 均以用户署名 squash 合并。最终源码 CI `37142168545` 通过，Contributors 仅 `2223M1`，未创建 GitHub Release。

## 交付内容

- 岚之拳、龙回旋踢及东尼对应组件采用单个原生多段攻击指令，整次攻击享受活力。每段伤害仍等待对应动画命中；掌打、对空砰砰拳、龙卷拳纳入回归。
- 巴投跳过为无贴图的原生占位身体创建残影，修正皇帝蟹左右钳的空引用中断。普通怪物的残影及原有耗茶、格挡、虚弱保持。
- 龙·飞踢顺序为伤害 → 茶道呼吸 → 抽至原生手牌上限。同步三语描述、目录和东尼组件表；新抽到的茶道不追溯获得此次呼吸收益。
- 官网统计支持任意数量的版本组合，卡牌、图表、战报和本机 CSV 共用筛选。按实际样本计数合并，URL 保留多选，旧单版本链接继续有效。
- 卡牌模型 ID、93 张当前卡、奖励池、初始卡组和跑局存档结构不变。

- 每宿主 8 组龙·飞踢，覆盖基础／升级、有／无手中茶道、Normal／Fast，核对新生成／已有／新抽茶道及手牌容量。

- 375 项逻辑测试通过；网站／后台／Worker 73 项通过、1 项既有遥测夹具测试跳过。兼容清单、仓库校验、构建边界和最终主分支 CI 通过。
