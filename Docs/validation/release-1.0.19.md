# 1.0.19 官网反馈修复与名称统一

`Strike·打击` 在16种语言的标题、生成牌描述和卡牌目录中统一去掉中点两侧空格。模型ID、资源路径、存档键和原生 `CardTag.Strike` 保留。日语技术名按日本官方原作用语统一为「チャドー／チャドー呼吸」，修正半月圆规踢的错称；嘲讽明确空手道给予目标敌人。

官网基线116条公开反馈及发布前新增1条韩语一般好评逐条列在 [feedback-1.0.19.md](feedback-1.0.19.md)，含所有分类及已解决历史项；版本、附件哈希及判定记录在同名JSON。纯强度、无限构筑和内容愿望不作平衡调整。未经证实的兼容冲突不归咎于第三方，不新增私有实现适配、全局兼容框架或异常吞没。

## 已确认根因

- 沢渡继续游戏：原生主菜单使用 `NTransition.FadeIn`，旧版只等 `RunManager.FadeIn`。两入口共用事件实例的一次性启动，房间已离开或对局结束时不再启动。保存仍遵循原生房间进入前检查点，战斗中或决斗选择前继续会重新开始事件，不另建快照。
- 死亡与吞噬：死亡演出在 `IsDead` 更新前把主体和奈落覆盖层转交给死亡枢轴；AimPose旧回调仍寻找原节点并改写姿态。节点转交后交还死亡演出所有权，复活归还后再继续姿态同步。
- 角色预览：原生节点可以直接放在 `SubViewport` 下，父节点不能强转 `CanvasItem`。由节点原生全局画布变换和本地变换计算坐标，覆盖所有原先同类父变换调用。
- 韧性抽牌：生成状态牌后抽牌可能触发原生洗牌及 `Stratagem` 选牌。旧 `ThrowingPlayerChoiceContext` 会使动作异常中断；改用原生 `HookPlayerChoiceContext` 及其同步动作生命周期。
- 珊瑚锁血：多段处决预测重复使用原生 `HardenedShellPower` 剩余回合额度。预测扣除此前模拟损失，不修改真实能力计数；实际死亡和伤害继续由原生钩子处理。

## 处决演出追加调整

普通处决不再拉伸或压扁怪物，接近位置按真实原始边界计算，保留击退、倾斜、镜头、伤害及原生死亡流程。删除通用处决压缩状态、方向跟踪、恢复分支、锚点策略及只验证旧压缩实现的测试；不增加恒为假的开关或兼容分支。影响的调用方包括玩家、同伴、沢渡武器与黑暗忍者反击。

按追加要求，阿拉巴马落保留原有蓄力与落地压缩及模组角色排除规则。落地在伤害结算前围绕测得头顶补偿位移，将压缩后的头顶保持在地板接触点；处决直接保持该姿态，不再叠加通用压缩。原有死亡碎片演出不变。实机驱动新增三速度的原始体形、蓄力压缩、落地接触及单次死亡/资源释放观测；Mawler实测除接触标记外，每帧重新读取可见头部网格边界，三速度落地误差均为0。此证据不代表逐个怪物图集透明边缘的像素测量。

冻结验证发现ENet测试在另一端断言前开始下一张牌，后续洗牌会改变前一张牌的牌堆。仅在测试中加入两端完成断言的屏障；不改产品网络或动作队列。

## 发布前追加的卡牌与收招调整

用户编辑板 v1.20 与嵌入基线比较只包含三张改卡：嘲讽格挡15／18；忍耐为2费攻击、4／5伤害三次后获得4／5空手道（按用户后续修订）；强攻为1费、7／10伤害一次，保留抽4／5张并弃非攻击牌。16语言文本和卡牌目录同步，保留内容ID；旧 `EndurancePower` 类型和存档标识仍可读取，新忍耐不再生成该回合末能力。这三项为用户指定变更，不由反馈中的强度建议推导。

攻击收招依据两宿主的 `animations/characters/ironclad/ironclad.skel`、`ironclad_skel_data.tres` 和 `CreatureAnimator.SetNextState/AddNextState`。真实Spine轨道读取普通攻击35／30秒、重击46／30秒；idle提前0.05秒混入并在原轨道终点完全接替。两版结果一致；非循环攻击不使用循环idle的随机time scale。原生 `CreatureCmd.TriggerAnim` 仅缩短快速模式的出伤害等待，不加速该轨道。

因此普通攻击和重击的最终位移及姿态回收使用各自完整轨道减去实际前摇后的时长，不再共用0.1秒视觉回位。普通、快速模式不把收招再乘半速系数；瞬间模式仍直接复位。保留现有命中等待、多段之间的0.1秒回位及下一动作接管行为，未增加操作锁定。居合、翻滚、腾空和龙卷维持自身编排。契约以真实Tween半程/终点观测位移和姿态，分别检验游戏结算后仍在收招、最后回到待机及跨动作接管。

旧视觉包在同一最终回位半程断言失败，新两宿主产品通过。三卡覆盖原生Strength/Vigor、多段命中顺序、指定目标、费用和旧回合末能力不再生成；忍耐由ENet两端分别作为所有者测试基础与升级卡。现有AutoAnthony公共组件桥接同步新配方，修复强攻旧配方读取已删除Repeat变量的失败，生成的忍耐保持三段攻击后获得4／5空手道；没有修改AutoAnthony模组。

## 随机序列与未解决项

商店／宝箱附件证实剩余遗物序列为空后发生越界；同日志有回溯保存错误，但缺少出错对局的存档，无法证明空状态的生产路径。原生新局、真实反馈存档导入／继续时再保存／再读取验证保留399（stable）及393（preview）个剩余值及消费顺序。未改 `SingleplayerSeedRules`，没有补满、重抽、回退原版投掷或猜测旧档修复。

CFC所有权标记排除契约不等同于实际CFC共存实机测试；当前机器未找到CFC二进制，因此实际共存及历史回溯模组组合未执行。玛卡古、半月挡伤和现有茶道／黑炎／蜂群等契约通过，只能证明所测当前行为。人物压扁、持续龙卷、历史生成牌异常等仍缺乏完整最小复现；保持未解决，不合并关闭症状相似的条目。

使用真实 stable 0.107.1、preview 0.111.0 程序集；两宿主完整产品契约、Patch安装与逐目标回滚、原生存档序列及双进程ENet已通过开发验证。韧性＋Stratagem选牌链在preview两端分别作为所有者测试；旧1.0.18在同链抛 `NotImplementedException`，新链完成选牌、抽牌和后续动作。旧包死亡节点交接与锁血预测均有失败基线。
