# 黑暗忍者暗·打：插刀定位（2026-11-18）

预览版 0.113.1 的 `NImpaledArrowVfx` 会让箭随目标移动；无 Spine 箭槽时用 `ArrowPosition`，再回退到原版受击中心。暗·打采用这两个定位点，沿用自己的前后刀段、刺入深度和收刀节奏。忍者杀手的 `NinjaSlayerAimPose.SetCore` 和瓦皮的 `NCreature.WuppyTweenHelper` 都会更新受击中心，不再额外叠加身体位移。

在 Godot 场景树中调用产品 DLL 的暗·打演出。旧 DLL 在命中停顿期间，目标位移 `(60, -35)`，刀的位移为 `(0, 0)`；修正后两者均为 `(60, -35)`。正式版 **0.107.1** 和预览版 **0.113.1** 都通过了已摆姿势目标的初次定位、1.25 倍缩放、连续刺向两个不同定位点、第二个目标提前移除、命中闪光位置与独立返程的断言。验证为无窗口场景测试，未做实机录像或多人联网测试。

## 瓦皮、友军和转机补测

- **回血与偷牌分开结算。** 上表四种代挡情形中，黑暗忍者均从 400 回到 414。直接把 50 生命的瓦皮作为暗·打目标时，瓦皮降到 36，玩家仍为 500，牌组中的测试牌仍在，没有偷牌能力。玩家实际承受溢出伤害时仍按原规则偷牌。
- **友军站位。** 没有模组友军时，普通宠物进场或敌人增援不会触发模组重排。有友军时，本地瓦皮沿用 0.113.1 的 `NCreature.PositionWuppy`：独处时相对主人命中框右边的水平偏移为 50、高度偏移为 −50；奥斯提存活时分别为 −25、−250。最后一名模组友军离场后仍为后者。四个本地玩家视角下的队形、远端宠物和纸鹤原有回归均通过。
- **联机交互。** 用本地玩家与另一玩家持有的小季、瓦皮搭建场景。选择援护牌或可用药水时，远端小季的鼠标命中框开放、手柄可取得焦点；取消、换不支持的牌、或原版禁用交互时恢复限制。普通宠物不能通过药水的手柄候选列表。这里验证的是双持有者场景和原版导航接口，没有连接两台设备。
- **已插在黑暗忍者身上的愚者箭。** 使用 0.113.1 真实 `NImpaledArrowVfx` 场景及三个 `ArrowSlot`。验证突刺换位、返程翻转时两段箭保持前后关系；留存的箭复位；拔出的箭由原版完成回收；销毁的箭没有残留。模组不更改箭槽状态。
- **转机。** 两个宿主都对基础和升级卡分别生成攻击、技能、能力、状态牌；只有本人生成状态牌才抽 1／2 张。另测了叠层、三个目标牌堆、已有牌移动、无生成者和他人生成。16 种语言的卡面与能力说明均恢复状态牌限定。
