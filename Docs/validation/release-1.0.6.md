# 1.0.6 韧性升级修正

基线为 1.0.5 后续目录与证据提交 `009d3c578bef52c6f0dc40f3b90c83d5e21e527f`。韧性的升级实现原本同时执行 `Cards.UpgradeValueBy(1)` 和 `AddKeyword(CardKeyword.Innate)`，因此升级卡既增加抽牌又获得固有。

按用户要求删除升级新增固有，保留抽牌 1→2、1 费和原有状态牌抽到触发。三语描述及悬停由原生关键词生成，无需另写显示条件；卡牌目录和既有基础／升级元数据期望同步。无模型 ID、Power、存档字段或其他卡牌效果修改。

## 验证

- 375 项逻辑测试通过；网站、Worker 和后台测试 71 通过、1 项既有跳过。仓库一致性、兼容清单、构建边界及差异格式检查通过。
- 最终提交的 stable 0.107.1／preview 0.111.0 产品、SmokeDriver、可选东尼程序集、通用包及完整 DLL 契约通过。既有 93 张卡牌契约直接实例化基础／升级模型，核对韧性两版费用 1、抽牌 1／2、关键词为空。
- 本机 Windows 隔离后台桌面从通用包根加载器进入角色选择、首战和重启读档，两宿主均通过；既有手里剑、奈落生命、处决 UI 固定和反向处决归位回归也通过。实际 RitsuLib 0.6.5，编译兼容包 0.5.12。
- 最终重建的首次 Godot headless 导入因 `EditorSettings` 断言退出，日志保留在本机 `build/release106/build-preview-import-failed.log`。没有改代码或绕过检查，重新启动完整构建后，导入、双宿主构建和契约均通过。
- 契约进程退出仍有既有 Godot 资源释放警告，不宣称日志零警告。未提供同宿主遥测跑局夹具的重载项目仍为 NOT RUN。

[Workshop 3776911445](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445) 重新下载后，12 个文件 SHA-256 与最终通用包全部一致，版本为 1.0.6。三语标题和介绍分别查询并逐字校验；公开状态、`characters` 与支持语言标签、RitsuLib 依赖、方形预览、16:9 封面和画廊保持。新更新说明严格匹配 `我们修复了一些问题，增添了一些内容，调整了一些东西。`。

源码、DLL 散列、宿主 MVID、实际依赖和最终实机检查点见相邻 `release-1.0.6-evidence.json`。

发布核验及目录导入后清理 6 个生成目录，共 962,974,043 字节，包括双宿主构建、加载器输出、重复通用包、临时目录导出和上传暂存。精简日志、宿主参考、源文件及 Steam 安装包保留；本轮后台桌面计划任务已移除。
