# 1.0.6 韧性升级修正

基线为 1.0.5 后续目录与证据提交 `009d3c578bef52c6f0dc40f3b90c83d5e21e527f`。韧性的升级实现原本同时执行 `Cards.UpgradeValueBy(1)` 和 `AddKeyword(CardKeyword.Innate)`，因此升级卡既增加抽牌又获得固有。

按用户要求删除升级新增固有，保留抽牌 1→2、1 费和原有状态牌抽到触发。三语描述及悬停由原生关键词生成，无需另写显示条件；卡牌目录和既有基础／升级元数据期望同步。无模型 ID、Power、存档字段或其他卡牌效果修改。

## 验证

- 375 项逻辑测试、仓库一致性、兼容清单和差异格式检查通过。
- 既有 93 张卡牌契约直接实例化基础／升级模型，核对韧性两版费用 1、抽牌 1／2、无固有。双宿主最终 DLL 和发布结果在核验后补充。
- 工坊自动说明沿用固定句子；公开状态、三语介绍、图片、`characters` 及支持语言标签和 RitsuLib 依赖保持。

不使用 ninja5080，不新增截图或录屏。macOS／Linux 实机未执行；本轮不重部署 Worker，不创建 GitHub Release。
