# 玩家文案与三语支持验证

本轮基于 f79527ca9f92007ccc8953f413f91217cc1b3ffd 的干净工作树，沿用版本号 0.3.6。改动留在本地，没有提交 Git，也没有更新工坊、GitHub Release 或线上网站。

## 改了哪些地方

三份首页、工坊介绍与更新稿改为面向玩家的短说明。保留安装依赖、支持版本、平台限制、旧局提醒、作者署名和授权边界。中文按 human-writing 修订，玩法介绍参考 Winefox，网站用语参考 Spire Codex。

设置、反馈确认与隐私说明采用一致的三语表述。首次提示被关闭后的默认开启行为、战报单独授权、反馈正文公开、截图和日志不公开、等待上传与上传完成的区别均保留。

三语各有 16 张本地化表、622 个键。日文覆盖 93 张卡牌、16 件遗物和其余玩家界面。英文补齐先古与卡牌附加状态说明，三语补齐黑暗忍者遭遇名称。问候气泡改从语言表读取，演出与配音不变。

网站新增语言选择，保留筛选条件并记住选择。反馈原文不翻译，后台管理页仍用中文。网站的历史目录不回写；当前已发布的 0.3.5 目录缺少日文时会明示英文回退。候选包可以导出三语目录，正式导入仍须走现有的发布核验流程。

运行时改动只有问候文本读取与设置的备用文字。已审定的中英文卡牌、玩法、数值、内部 ID、图片和音频未改。导出工具额外清理原版的关键词与药水提示缓存，避免连续导出三种语言时串用第一种语言。

## 已知边界

原版宿主测试使用隔离存档和网络阻断，不安装到普通游戏目录。Catalog 测试核对打包文件、实际语言表与卡牌格式化，不等于逐页游戏界面截图验收。事件、先古对话、设置和问候气泡在所有分辨率下是否截断，仍需完整人工游玩检查。macOS、Linux 与 Steam Deck 未测。

部分日文招式的逐字原文仍未核实，已在[日文依据表](../localization-ja.md)标明。飞刃席卷的现有中英文卡面比实际效果窄，本轮按要求保留；日文与能力栏按当前代码写成全部手里剑。

首次测试版目录导出在 240 秒超时。随后避免了跨语言重复编码同一张图片，并延长测试时限。新增关键词检查曾因调用原版内部扩展方法编译失败，已改为直接读取原版语言表。

导出日志中的 DuelRoundBridgePower 缺少标题属于不可见后台能力，未添加玩家名称。原版测试用 Mock Power 也不属于模组缺译。测试环境有图形设备警告，不能据此宣称游戏内视觉验收完成。

npm ci 提示既有依赖含 4 项高危安全审计项。本轮没有扩大范围升级依赖，也没有执行自动修复。
