## 验证

- stable 0.107.1 与 preview 0.111.0 正式包构建、完整玩法、沢渡手柄专项和补丁安装／故障注入／回滚契约通过。手柄专项覆盖全部动画速度、单／双选项、导航和确认、鼠标与手柄切换、地图覆盖和旧动画回调。
- 367 项逻辑测试通过；网站与 Worker 测试 82 项通过，1 项因未提供额外原版遥测样本而跳过。仓库、兼容配置、16 语言网页文案、工坊说明传输和差异检查通过。
- Steam 回下载全部 12 个文件的路径、大小及 SHA-256 与冻结包一致。更新说明逐字一致，16 语言标题／描述、所有者、公开状态、依赖、预览图及忽略大小写后的标签集合保持一致。
- 同一正式包导出 16 语言、1672 个模型的官网目录。全部模组卡牌字段与 1.2.2 完全相同。官网 `current.json` 推进至已验证的 1.2.3，版本筛选将 1.2.3 并入 1.2.2，历史目录保持不变。
- 真实公开快照的 14,674 局、4,918 胜及战斗分母在合并前后完全一致；48 个已有样本版本合并为 30 个可选卡牌版本。浏览器确认旧 1.2.3 链接归为 1.2.2、多选正常、列表不再单列 1.2.3，控制台没有错误。

没有实体 PS5／Steam Input 验收、完整图形游戏重放或新增跨平台及 Steam 联机测试。打包扫描存在开发缓存 CSV 的重复 UID 提示，目录导出存在原版图集／能量前缀警告；不把契约通过表述为所有日志零警告。手柄专项的最终日志无 Godot 错误／警告。

官网源码、版本分组和已验证目录随本记录提交，由既有 Pages 工作流部署。线上核验记录另保存在 `build/validation-1.2.3/live-pages-evidence.json`，部署完成前不把本地预览当作线上结果。
