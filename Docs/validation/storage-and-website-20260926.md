统一预算在 R2 预留容量达到 7 GB 后从最早上传对象开始清理，8 GB 为写入上限；每天最多预留 2,000 次对象写入与 20,000 次未缓存公开读取。每天到期清理，压力清理每分钟续批；删除成功才释放容量。原生生命周期另行处理到期及孤立对象。反馈与战报最长保留 180/90 天，容量清理可提前删除旧正文，不删除汇总统计。预算只覆盖本项目控制的访问，不是 Cloudflare 账户级扣费开关。

实测修复了 gzip 传输与缓存二次编码：R2 中保留 gzip，读取时通过原生 `DecompressionStream` 输出 JSON，由 HTTP 边缘决定传输压缩。真实冷缓存/命中缓存共 8 次读取均与原记录解压后的 JSON 一致；迁移临时入口已移除。对应生产部署 ID 为 `36109f69-22a0-4287-96da-f34bbd80551e`。迁移备份和含私有键的证据仅在原工作区 `build/r2-migration/`，不提交。
