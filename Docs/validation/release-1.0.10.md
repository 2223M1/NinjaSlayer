# NinjaSlayer 1.0.10

- 聚气、啜饮基础与升级费用均为 0；聚气升级保留、啜饮升级立即呼吸及原有效果保持。
- 纳入旧工作区 2026-10-04 的龙卷拳音效修正：只要求前奏在最后一击前播完，命中后尾音自然结束。正常速度至少 5 段、快速至少 9 段满足时长；瞬时和全奈落仍逐击音效。删除处决命中后停顿、返程对资格的错误加时。
- 当前 X≥4 时双倍段数及原生多段 AttackCommand 保持。未迁入旧工作区的旧卡牌效果、旧模型 ID 或其他未发布内容。FMOD 银行、GUID、源素材及音量保持线上版本。

- NSTV记者证不再向建筑师对话注入“取材”；三语说明明确例外。正常继续、问候、处决和一次胜利结算保留。

## 验证

379 项逻辑测试、仓库／兼容清单／构建边界检查通过。正式 0.107.1 与预览 0.111.0 产品、SmokeDriver、完整 DLL 契约及 preview 可选东尼契约通过。93 张牌元数据覆盖两张卡的基础和升级 0 费；现有结算测试覆盖聚气消耗手牌茶道取得空手道、啜饮呼吸及持续效果。

隔离真实游戏通过通用根加载器启动，并运行首战／重启与既有 Release038 场景。真实 FMOD 检查长连击循环、暂停冻结、尾音和原生 STOPPED；新用例检查 Normal X3、Fast X4、Fast X5、Instant X5 的音效选择与自然释放。Fast X5 实际 10 段启用 Spin，Fast X4 实际 8 段仍逐击。

带记者证进入建筑师，检查前后两页对话无“取材”，点击继续并验证胜利只结算一次。

源码、DLL 校验值、宿主 MVID、RitsuLib 0.6.5、东尼 0.3.119、逐项实测 checkpoint 与工坊下载核验见 release-1.0.10-evidence.json。未进行 macOS/Linux 实机或独立多人客户端验证。奈落生命联机黑屏仍等待玩家日志，本次不声称修复。

工坊保持公开、三语介绍、图片、characters 标签和 RitsuLib 依赖，更新说明使用既定统一句。官网目录从已核验运行包导出；不新建 GitHub Release。清理本轮重复构建与上传暂存，保留源码和精简证据。
