# 0.3.7 发布核验

发布源码为 `5907cb4b9e31de716b077394e09f20f7ce31861f`，由 [PR #143](https://github.com/2223M1/NinjaSlayer/pull/143) 合入。版本标签为 `v0.3.7`。

本次发布包含玩家文案精简、游戏及网站的中英日支持，以及用户追加要求的 R3 音效。没有改动玩法、数值、卡牌 ID 或图片。R3 相对上一版降低 50 个角色事件的音量 1 dB，提高两个旁白事件 2 dB；音乐、选人和转场不变。

## 已执行

- 主分支 CI 通过，运行编号 `36541138773`。本地仓库、兼容性同步、构建边界和差异空白检查通过。网站测试 55 项通过、1 项因缺少原生数据样本跳过。
- 0.107.1 与 0.111.0 的正式安装包均构建成功。两套真实宿主加载同一最终通用包，完成三语本地化检查和运行时目录导出。
- 最终 PCK 内的音效 bank 哈希与 R3 输入一致，音乐 bank 与 0.3.6 一致。此次不把哈希检查当作人工听验，也没有重跑全部音频场景。
- GitHub 的正式版、测试版、通用包共三个附件全部重新下载，逐包 SHA-256 与本地发布产物一致。
- Steam 工坊重新下载的 12 个文件全部匹配本地发布包，版本为 0.3.7。RitsuLib 依赖和不公开列出的可见性保持不变。
- 依用户发布后要求，工坊介绍正文已清空，并通过 Steam API 读回确认。用户确认保留工坊上的简短更新记录“更新了一些内容”；已读取公开更新页核实。GitHub 仍保留三语更新稿。
- 网站目录来自同一已发布包的 stable 宿主导出，三语各有 1631 个模型条目，其中模组卡牌 93 张。已核对导出 DLL 属于远端下载包；新增 0.3.7 目录，没有改写历史目录或图片。

详细文件哈希和宿主验证记录见 [发布证据](release-037-20260929.evidence.json)。网站部署由本次目录提交触发，部署是否完成应以对应 Pages 工作流与线上版本核对为准。

## 范围限制

未逐一验证所有分辨率下的每页事件、设置和选择界面，未完成日文完整通关，也未验证 macOS、Linux 或 Steam Deck。原有中英文卡牌文案与代码的已知差异、日文暂定译名继续见 [日文说明](../localization-ja.md)。
