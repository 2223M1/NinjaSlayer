# 1.2.8 发布记录

[Workshop 条目 3776911445](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445) 已上传并回下载验证为 **1.2.8**。产品源码冻结于 `a9870699529ecb02635fddbda8d058bf01e2f7cc`，Steam 内容 manifest 为 `489619144269440199`。

## 改动

- 从容弃牌获得拉伸。柔术空手道调整为 3→5，Chop打击伤害为 9→12、下回合空手道为 3→4，连打空手道为 4→5。转机生成任意牌时抽牌，交叉防御仍跳过能力牌，并使 Chop 回手。
- 浴火、手里剑风暴移除消耗，飞刃席卷瞄准提高至 6→8。攻势不息升级获得保留，回合末仍打出一张攻击牌。精简手里剑、茶道呼吸、残心与正面效果显示，替换谋定卡图。
- 奈落解放战斗开始获得 20 点奈落生命，每个己方回合开始加入一张黑炎。在本人首次触发原版计策所用的 `AfterShuffle` 前，手牌有攻击牌时必须优先手动打出攻击牌。开局和队友洗牌不计，不给卡牌追加词条；自动打出与原版执迷诅咒保留原有规则。
- 奈落事件移除指定牌组要求，含忍者杀手的队伍按普通第三层事件池出现。多人各自选择，不投票；接受的其他角色也切换为奈落外观与音效，保留角色身份、牌组和各自的遗物效果。
- 现有平衡遥测已上传原版最终选项记录。新增 `Naraku event choices` 手动工作流与匿名统计工具，按每位玩家每次事件的最后选择统计接受／令其闭嘴占比，排除中间呼唤并沿用重复上报及 SL 去重。只涵盖同意遥测且已完成胜负的对局。

## 验证

- 正式版 0.107.1 的 177 个完整检查组、预览版 0.113.1 的 179 个完整检查组通过；双版补丁安装、故障注入及回滚通过。使用 RitsuLib 0.6.13。
- 奈落检查覆盖混合角色队伍各自的事件进度、伤害、选择、奖励和洗牌限制；正式版五个、预览版六个原版角色均通过真实模型工厂、可见外观、死亡／复活动画提示、攻击／受击音效和原角色牌组保持检查。
- 367 项逻辑测试、4 项事件选项统计测试通过。网站与 Worker 测试 82 项通过，1 项缺少额外遥测样本而跳过；仓库、16 语言网站文案及中文工坊更新说明检查通过。
- 从最终 DLL、PCK 导出 16 语言、1859 个模型、93 张模组卡牌。核验调整数值、关键词、能量图标、黄色正面效果列表和谋定新卡图。
- 回下载的全部 11 个文件路径、大小和 SHA-256 一致，中文更新说明逐字一致。工坊的 16 语言标题、介绍、公开状态、依赖、预览图和标签保持原值。
- 官网导入同一份经过回下载验证的目录；本次包含卡牌机制变化，1.2.8 单列为卡牌统计版本。

## 验证范围

本次运行精确双版宿主 DLL 的自动检查，没有重跑完整图形客户端。正式版展示测试使用 0.113.1 PCK，建筑师另使用精确 0.107.1 原始骨骼。多人自动场景不等同于真实 Steam 联机；实体手柄、macOS 和 Linux 实机未新增测试。

日志包含预期故障注入异常、Godot 退出资源警告及原版目录的能量图标提示。完整日志与散列保存在 `build/validation-1.2.8/final/`，详见 [发布证据](release-1.2.8-evidence.json)。
