# 预见选中框与奈落解放（未发布）

0.111.1 和 0.113.1 的 `src/Core/Nodes/Screens/CardSelection/NSimpleCardSelectScreen.cs` 在 `OnCardClicked` 中记录选中牌；`src/Core/Nodes/Cards/NCardGrid.cs` 的无参 `InitGrid` 在重建布局时替换卡面节点，没有恢复已选牌的边框。滚动时重新分配牌行的 `AssignCardsToRow` 已经处理高亮，无需再改。修复只对预见界面的网格生效。

使用两版原版 Godot 卡牌网格、资源和三张同名牌做了无窗口对照：只选第一张，确认原版材质的边框宽度已升起，再改变网格宽度并确认卡面节点已替换。未启用修复时两版都丢框；启用后两版都只恢复第一张的框，取消后再次重排也没有残留。独立的 Release100 客户端鼠标回归已加入相应检查，并通过双版编译；本次未运行完整图形客户端。

奈落解放的开战数值由 20 改为 30，全部 16 种语言的遗物说明均引用同一数值。正式版与预览版的玩法回归分别通过 180、185 组，含多人遗物归属、开战发放、回合不重复发放及读档重开；两版的补丁安装与回滚检查均通过。
