## 实际修改

- 地狱龙卷：敌方处决演出预判某玩家将死、实际却存活时，不能提前清除该玩家的持续龙卷视觉。`FinisherSession.Begin`仅取消普通动作，确认死亡后才完整清理；保留原生死亡清理。此前提前Reset使下一回合减速任务永远无法完成，阻塞出牌和结束回合。没有添加超时回退、重置玩法状态或第三方分支。
- 炎甲：10→12格挡、4→5奈落生命，保留向抽牌堆加入1张黑炎。复用原生`GainBlock`、`PowerCmd.Apply`和已有生成牌命令，16语言动态描述、AutoAnthony已有奈落组件及目录同步。
- 茶道：基础1费，升级0费；保留累计能量与消耗，通过原生`EnergyCost.UpgradeBy(-1)`实现。
- 日文：大受身标题改为`グレーター・ウケミ`；强手里剑改为`ツヨイ・スリケン`，同步星无之夜卡牌与能力中的引用。现有`チャドー`命名保持一致。

日文命名证据：公开反馈`8a23803f`明确给出两项译名。原文事实：中文语料存在“大·受身”招式，见[第二部｜Geisha Karate Shinkansen and Hell｜p2-c008-s03.md:61]。设计推论：采用日本玩家提供的招式称呼并统一引用。不确定：本地中文语料不能独立证明日文假名写法，不将其声称为日文原著引文。未提交语料。

## 故障证据与边界

- **龙卷：**`b7aaef2f`附件`logs/godot.log:67089–67141`，实验体第三阶段攻击，反向处决session21预判两名受害者，一人死亡后记录`forecast did not match runtime damage`。调用链中`Begin → CancelAndRestore → HellTornadoVisual.Reset`清除了存活者的持续演出；下回合`Decelerate`返回的任务失去`_Process`推进。旧工坊1.0.25的实际DLL在同一契约报`Reverse finisher disabled the surviving player's Hell Tornado in Normal`，候选通过。
- **事件开战：**`bb5a11f1`附件`logs/godot2026-10-13T22.56.05.log:1948,2063`，`LexNinja2Code.Relics.ToiletWater.AfterCardDrawn`调用不存在的`CardCmd.Exhaust(PlayerChoiceContext,CardModel,bool,bool)`，导致原生战斗循环退出。日志报告LexNinja2版本`v3.0.4-beta-0-g225af56`、程序集`3.0.4.0`。建议更新为支持当前游戏的LexNinja2，或暂时禁用；NinjaSlayer不垫旧接口、不吞异常。没有取得该历史二进制做复跑，结论基于直接异常及调用点。
- **色彩哲学家：**`20b91778`附件`logs/godot.log:4230,4329`有`CharacterModel.AddDetailsTo → EventOption.AddLocVars → ColorfulPhilosophers.GenerateInitialOptions`空引用，截图无选项。两版原生实现表明缺失选项描述键会传入null。NinjaSlayer未加入`IModColorfulPhilosophersCardPool`；仅NinjaSlayer+RitsuLib时生成3个有效选项。报告含KeystoneRunes、BaseLib、HextechRunes、LexNinja2、ModConfig、SpeedX、LieRenTVmod、Remilia、newsanguo、BodyBurst；具体缺失键和所属模组尚未证实。没有复原报告全部历史第三方版本，不凭安装列表归责。
- **实验体力量：**`a21fa028`为四人联机，含Madoka、BaseLib、ChiikawaMod、Downfall、RitsuLib和NinjaSlayer。截图为结算页，当前日志有大量Chiikawa Godot错误但不足以连接到力量变化。局史未见钩绳使用，镣铐药水是放弃的奖励。钩绳减力量直接继承原生`TemporaryStrengthPower`的回合结束恢复，实验体复活只设置生命；没有足够证据支持改动或认定责任。
- **闪退：**`51f82c67`附件分别记录`CreateResource failed 0x8007000e`（21.17.44日志）、`DXGI_ERROR_DEVICE_RESET`（21.21.13日志:2216）、`DXGI_ERROR_DEVICE_REMOVED`（21.41.06日志:9091）。这些证明图形资源/设备失败，但不能确定触发源。没有添加内存/GC全局控制或归责联机消息。
- **卡顿：**`841ca548`未包含帧耗时或具体动作定位；boss捕捉回退及屏幕震动目标缺失不足以证明性能根因。
