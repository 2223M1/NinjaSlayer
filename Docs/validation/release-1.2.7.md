# 1.2.7 发布记录

[Workshop 条目 3776911445](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445) 已上传并回下载验证为 **1.2.7**。产品源码冻结于 `fe36915748fdd05129d66fccedd35c494ed8bee8`，Steam 内容 manifest 为 `7214006047024192187`。

## 改动

- 残心在获得当前未拥有的正面效果时抽 1→2 张牌，效果耗尽后再次获得可以重新触发。正面效果范围增加瞄准、翱翔，相关卡牌侧栏列出完整的 16 种效果。
- 嘶哈改为获得 4→5 层再生。飞刃席卷改为获得 4→6 点瞄准，保留 2→3 层手里剑。瞄准增强同次预见或激发的整批手里剑，也增强强手里剑，结算后消耗本次使用的瞄准。
- 海军战锤固定打出攻击牌两次，不再强制消耗被打出的牌；升级移除自身消耗，重放间隔与原版一致。聚气升级倍率提高至三倍，保持 1 费。
- 取舍更名为舍念并更换卡图；原舍念重做为破瓦正拳，3 费、30→38 点伤害，已有正面效果增加 2→3 层，使用崩拳的特殊重击动画。柔术获得 3→4 层空手道，下回合获得 1 点能量。
- 杀气恢复格挡后获得直气的机制，格挡为 10→12；升级版生成直气+，混合、多次打出分别累计奖励。直气及直气+均为 1 费。
- 建筑师处决仅从牌组现有卡牌选择，优先级为阿拉巴马落、特殊重击、踢击重击、踢击轻击、普通重击、普通攻击；同档按牌组顺序，没有可用卡时播放普通攻击。临时手牌不参与，也不修改牌组。
- 适配预览版 0.113.1、RitsuLib 0.6.13，保留正式版 0.107.1。按宿主分别使用建筑师原版骨骼资源，保持处决与完整出屏。
