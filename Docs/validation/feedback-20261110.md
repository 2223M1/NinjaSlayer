## 追加：阿拉巴马落的帝皇蟹钳子

`AlabamaDropAnimation` 保留原有伤害、抬升、翻转、落地和回位时序。新增 `AlabamaClawMotion`，将目标占位身体的画布变换传递给原版 `%ArmBoneL` 或 `%ArmBoneR`。两个宿主的 `scenes/creature_visuals/kaiser_crab_boss_setup.tscn` 均使用 `bone_mode=1`，分别驱动 `claw_l_offset`、`claw_r_offset`；直接复用原版骨骼控制节点，无需复制钳子图片或移动共享主体。

骨骼在动画应用前读取位移，并在绘制前以零时间增量更新，保证与 Tween 同帧。存活回位、快速出牌视觉尾段结束、死亡交接和节点离树均释放控制并恢复原版偏移；死亡时先释放，避免覆盖后续死亡动画／爆炸捕获。空白占位节点不再生成无像素的旋转残影。卡牌玩法及文案未改变，因此此追加项不改卡牌目录。

新增 `OrbContractRunner.AlabamaClaws.cs`，双宿主运行完整 `AlabamaDropAnimation.Play`，验证两只真实骨骼分别抬升超过700单位、翻转、仅结算一次、独立于另一只钳子及主体、存活复位、死亡前释放及离树清理。后台 OpenGL 图形验证通过，已查看 `render/alabama-before.png`、`render/alabama-left-lift.png`、`render/alabama-right-lift.png`，实际钳子图像正确移动。既有帝皇蟹爆炸契约继续通过。

本项只新增一个具有骨骼变换和事件订阅生命周期的局部对象；无反射、动态补丁、运行时兼容探测、锁、兜底路径或全局 GC 设置。原版绑定及骨骼节点相同，生产代码不需要新增宿主分支。
