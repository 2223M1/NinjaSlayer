# 1.0.5 加载修复、强·手里剑与本地整合

基线为已发布 1.0.4 的 `d3dcd495523785104d0968935a537f11ee999840`。仅整合当前发布工作树；旧混合工作区、玩家反馈包和外置制作工具不进入提交或运行包。

## 修复与范围

- 玩家 2026-10-03 17:39 的反馈日志显示 macOS / Apple M1 Pro / 0.111.0，仅启用 RitsuLib 0.6.5 和 NinjaSlayer 1.0.4。RitsuLib 已成功初始化；忍者杀手加载器拒绝宿主 MVID `57785517-0b16-42b9-8b36-bad6fb28384b`。用已发布 1.0.4 加载器复现同一拒绝。历史日志中的其他模组不作为这次最小组合失败的原因。
- 加载器改用原生 `ReleaseInfoManager.Instance.SemVer`，精确匹配清单中的 0.107.1 / 0.111.0，不再按平台 MVID 拒绝同版本游戏。缺少版本、未知版本或预发布后缀明确中止。必要补丁安装失败的中止规则保持。MVID 保留在诊断、构建参考和验证记录中。
- 通用包清单升级 schema 2，删除运行时 MVID 字段；保留版本目录、标记和 DLL SHA-256 校验，旧 schema、重复通道／版本及不完整包拒绝加载。
- 强·手里剑基础／升级固有关键词均为原生保留、消耗。0 费、原始伤害 6／10、获得时伤害快照和升级增加 4 伤害保持；没有新增字段、ID 或显示专用逻辑。
- 本机后台自动读取反馈，区分加载、失败与空列表；正文及处理状态合并读取，图片独立加载。使用 Wrangler 公共认证命令和 Cloudflare REST 减少重复进程。保存显示等待、成功或未确认失败，失败保留输入；私有附件、校验、过期和本机来源限制保持。
- 工坊介绍使用三种独立语言字段；标签为 `characters`，配置为公开。元数据同步不新增更新记录；游戏包自动更新说明仍严格为固定句子。详见同目录工坊语言验证记录。
