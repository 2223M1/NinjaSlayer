## 修正与证据

- 假商人事件：原生 `NFakeMerchant.AfterRoomIsLoaded` 所在场景将 CharacterContainer 缩放至 1.75；
  RitsuLib 0.6.3 在此创建商店立绘而非原生战斗形象，导致商店尺寸再次被放大。
  新增局部后置补丁，仅对忍者杀手商店纹理的 NMerchantCharacter 抵消该容器缩放，
  保留站位、其他角色和正常商店的形象。未改 RitsuLib 的布局或创建流程。
- 预见确认：实际原生鼠标输入复现。确认按钮下沿与消耗堆命中区域重叠，连续点击的后一次在
  预见界面关闭后打开消耗堆。普通、快速和瞬时模式均能复现；单击未复现。
  修复只把预见的原生确认按钮上移 120 个界面单位，在其 `_Ready` 缓存动画位置前修改场景偏移。
  原生按钮动画、窗口适配、键盘／手柄绑定和选择同步保留。通过预见专用三语提示键准确识别此界面，
  不修改其他选择屏，不设置鼠标延时或全局输入锁，不改变弃牌、奇巧、嵌套预见及手里剑发射时序。
- 本机后台、反馈原图／ZIP／文件预览、三语文案草稿与 PR 发布、战报请求取消与重试，见
  `local-intel-admin-2026-10-01.md`。后台不进入公开 Pages，私有反馈不提交 Git。
- Workshop 的 57 条历史说明正文已逐条清空；Steam 版本时间与回滚记录保留。
  自动发布说明统一为“我们修复了一些问题，增添了一些内容，调整了一些东西。”。
