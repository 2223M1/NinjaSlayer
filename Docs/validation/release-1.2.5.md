# 1.2.5 发布记录

[Workshop 条目 3776911445](https://steamcommunity.com/sharedfiles/filedetails/?id=3776911445) 已上传并重新下载验证为 **1.2.5**。产品源码冻结于 `35a659efa8873db8d0bc4917982bb0ff87675cf6`，Steam 内容 manifest 为 `1239004295536239123`。

本版支持正式版 **0.107.1** 和最新测试版 **0.113.0**，最低 RitsuLib 版本为 **0.6.11**。停止支持 0.111.0，移除固定随机数和东尼算法模块。玩法调整以 [工坊更新说明](../../Workshop/change-note.md) 为准。

## 验证

- 两版独立正式包和通用加载包构建通过。两版完整玩法、卡牌基础／升级元数据、补丁安装、故障注入和回滚契约通过，使用实际工坊 RitsuLib 0.6.11 运行库。
- 0.113.0 实际客户端在隐藏桌面、独立存档和独立安装目录中完成 Fresh、Resume、ReverseFinisher 三阶段，60 个检查点通过。覆盖加载、卡牌展示和变换、奈落生命、手里剑、黑炎、回避、暗打、踢技与终结技演出，以及战斗结束后退出、重新启动和读档。
- 367 项逻辑测试通过。网站与 Worker 测试 82 项通过，1 项因缺少额外遥测样本跳过；仓库、兼容配置、教程、16 语言网站文案、工坊更新说明传输及构建边界检查通过。
- 回下载的 **11 个文件**逐项核对路径、大小和 SHA-256，与冻结正式包一致；包内无 0.111.0 或 AutoAnthony 遗留。13 行更新说明逐字一致，公开状态、依赖、图片、标签及 16 语言标题／介绍均保持原值。
- 同一正式 DLL 导出官网目录，包含 16 种语言、1860 个模型和 93 张模组卡牌。目录导出与完整玩法契约分开执行，避免将导出模式的成功标记误作完整测试。
- 官网当前目录推进至已核验的 1.2.5。本次有卡牌数值和机制改动，使用独立的 1.2.5 统计分组。

## 范围与日志提示

0.107.1 使用精确宿主 DLL 配合已安装的 0.113.0 展示资源进行契约验证，没有进行正式版完整图形客户端测试。新版客户端关闭 Steam 和遥测并使用独立目录，但没有管理员防火墙隔离，不标记为 protected smoke。没有新增实体手柄、Steam 联机或 macOS／Linux 实机测试。

日志保留 RitsuLib 确认弹窗 `size_changed` 重复断开、选角期间 Godot `Invalid Task ID` 和退出资源回收提示；所有玩法检查点通过，本版不宣称这些提示已修复。补丁和终结技测试中的故障注入异常属于预期断言。打包阶段的开发缓存 CSV 重复 UID 提示也已保留。

详见 [发布证据](release-1.2.5-evidence.json)。完整日志、散列和本轮脚本保存在 `build/validation-1.2.5/`；官网部署完成后，线上目录核验记录保存在 `build/validation-1.2.5/final/live-pages-evidence.json`。

## 清理

回下载验证后，检查进程、绝对路径、Git 工作树、跟踪文件和目录链接，删除本轮重复构建包、官网导出副本、上传暂存以及五个隔离客户端目录中的游戏文件。保留验证日志、发布证据、源码和正常 Steam 工坊安装。清理前后磁盘可用空间增加约 **7.16 GiB**；此值来自磁盘可用空间差，不把硬链接文件的逻辑大小直接算作回收空间。
