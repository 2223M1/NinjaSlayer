# NinjaSlayer 1.0.12

预见在数量大于0时先调用原生 `CardPileCmd.ShuffleIfNecessary`。抽牌堆为空且弃牌堆有牌时，原生洗牌、随机流、动画与洗牌回调完成后，再读取新抽牌堆顶部并进行原有选择。飞刃轮转等洗牌效果照常生效；洗牌效果结束战斗时不再打开选牌界面。

抽牌堆非空但牌数不足时不补洗，两堆皆空或预见数量不为正时不打开选择。预见不实际抽牌到手中，原有弃牌、消耗、奇巧、嵌套预见、玩家归属及牌堆计数通知保持。嵌套预见开始时也遵循空牌堆洗牌规则，正在打出的奇巧牌不会被洗回。

按用户确认保持中英日预见悬停说明原文，仅在技术卡牌目录记录新行为；不改卡牌数量、模型ID、奖励池、初始牌组或存档字段。

## 依据与验证

正式0.107.1与预览0.111.0的 `Core/Commands/CardPileCmd.cs` 中，`ShuffleIfNecessary` 均只在抽牌堆为空且弃牌堆非空时调用 `Shuffle`。`Shuffle` 使用原生洗牌随机流，完成移动动画后等待 `Hook.AfterShuffle`，本次直接复用该公共入口。

契约覆盖空堆重洗、非空短堆、两堆皆空、零数量、不实际抽牌、洗牌后顶部顺序、飞刃轮转先结算再选牌、嵌套奇巧以及原有弃牌／消耗通知。实机沿用 Release100 场景，覆盖鼠标单击／双击确认和牌堆计数，并增加空堆重洗后的不选、单选、全选和消耗选择。

最终源码、DLL校验值、宿主MVID、RitsuLib版本、CI、实机检查及工坊下载证据见 `release-1.0.12-evidence.json`。未执行macOS/Linux或独立多人客户端实机；此前奈落生命联机黑屏仍待玩家日志，本次不声称修复。不使用ninja5080，不额外截图录屏。
