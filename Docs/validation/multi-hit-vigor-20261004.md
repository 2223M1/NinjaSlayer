# 多段攻击与活力

基线 `cccbe06b02b8838dbaeedb322598a063bfc17f43`（已发布 1.0.6 目录提交）。本记录是提交前候选验证，候选程序集沿用 1.0.6 版本标记；新版本发布证据另见发布记录。保留同时待发布的巴投／皇帝蟹修复。

## 原因与修复

stable 0.107.1 与 preview 0.111.0 的 `Core/Models/Powers/VigorPower.cs` 均在 `BeforeAttack` 关联当前攻击，在对应 `AfterAttack` 消耗攻击开始时的活力。`Core/Commands/Builders/AttackCommand.cs` 的 `WithHitCount` 在这两个钩子之间执行全部段数；原版 `TwinStrike.OnPlay` 使用这一入口。

岚之拳、龙回旋踢之前每段新建一条指令，因此活力只覆盖第一段。旧候选的实际 DLL 回归复现：3 力量＋7 活力时，基础龙回旋踢每个敌人的伤害是 17、10；消耗堆有两张茶道时，基础岚之拳是 20、13、13、13。额外增加一段的原生钩子也被错误地重复应用到每条指令。

两张牌改用一条 `AttackCommand.WithHitCount`，保留各段 `SlowAttack` 动画、命中效果和现有处决入口。岚之拳保留动态茶道伤害及固定目标；龙回旋踢保留群攻及回合末置顶自动打出。东尼 `area_multi` 组件同步修复。删除无生产调用者的旧逐段循环及 sequence 处决包装，测试及剧场计时观察改接实际出牌／原生攻击入口。没有改动原版活力，没有把不同次出牌合并成同一次攻击。

掌打、对空砰砰拳和龙卷拳本来已使用原生多段，纳入回归。卡牌费用、数值、关键词、模型 ID、93 张注册数及奖励池不变；卡牌目录补充结算规则。

## 边界

未执行跨电脑或独立客户端多人测试、macOS／Linux 实机及所有第三方组合。没有使用 ninja5080、没有截图录屏、没有改动日常游戏安装。契约进程有既有 Godot 退出资源释放警告。

初次新测试编译遇到测试夹具 API 名称错误，已纠正；旧的 gameplay-only 测试捷径缺少设置初始化，因此基线改用既有 orb-slots 捷径，最终两宿主跑完整契约。首轮新 SmokeDriver 缺失测试用命名空间及根节点属性写错，修正后两宿主实际运行通过。这些是验证代码修正，没有给产品增加回退路径。

原始精简日志保存在本机 `build/multihit-vigor/`。本轮发布获用户后续授权，最终版本需从干净合并提交重建并另行验证。
