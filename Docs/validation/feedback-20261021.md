## 本地修改

- 暗忍災禍：删除按本地画面横坐标排序目标的逻辑，直接使用原生目标顺序。原版`NCombatRoom.PositionPlayersAndPets`将各端自己的玩家放在布局首位；原来的演出顺序因此会改变偷牌随机数分配。附件双方生命、能力、RNG计数一致而被偷卡牌不同；未改代码的相反站位测试失败，修复后两版及双进程测试通过。
- 低血量喷血：创建特效前确认存在忍杀自己的身体Sprite。对复制角色或外部皮肤不假设相同节点结构；身体节点释放后，逐帧更新和绘制回调均结束特效。原版候选在外部视觉替身上复现RecordHead空引用，修复后外部视觉无异常、正常身体仍创建特效、身体销毁不遗留演出。附件环境含GensokyoSpire0.5.1、MomoLib1.3.7、RitsuLib0.6.7；只修已证实的边界错误，不归责这些模组、不宣称整体帧率已优化。
- 回避：用户本轮明确新语义。旧版每个命中段消耗一层，符合旧说明；现在同一原生`MoveState.PerformMove`内的单段、多段和多次伤害命令共用一层，敌人行动完成后通过原生`PowerCmd.Decrement`扣层。无攻击不扣层，下个己方回合移除剩余层数。复用已有行动作用域及命中记录，未新增全局兼容框架；敌人行动之外的独立伤害命令仍按各自命中结算。16语言能力说明和卡牌目录已同步。
- 对空砰砰拳：奈落生命本已属于`PowerType.Buff`，但固定计数名单漏了它。补入名单，任意正层数只算一种；原生CalculatedVar与实际攻击共用原判定。同步现有AutoAnthony组件，未扩大其他能力名单、未新增对外API。
