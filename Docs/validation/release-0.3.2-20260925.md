- 本次新卡图为两个工作区中同一批19张PNG，按源文件SHA-256固定快照。相对0.3.1另包含新卡 ShurikenDraw 复用的卡图。全部卡牌保持93张，普通奖励池20/35/25，初始卡组不变。
