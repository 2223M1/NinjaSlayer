# 1.0.21 韩语校订与杀气·直气

本版包含 PR #202 的韩语校订，以及小季事件、崩拳、柔术、杀气·直气四项明确玩法调整。韩语校订的来源、语义差异及保留项见 [korean-board-corrections-20261010.md](korean-board-corrections-20261010.md)。

## 行为

- 小季事件只在第二层、队伍中有忍者杀手时进入原版事件池，移除原来的第二层宝箱后至第三层宝箱前限制。
- 崩拳伤害从 10/14 改为 20/28，保留 5/7 空手道。
- 柔术移除弃牌和选牌，保留 1 费、3/5 空手道与消耗。
- 杀气改为杀气·直气，保留 2 费技能，给予 9/12 格挡。己方回合结束时锁定攻击意图敌人，敌方回合结束时，若期间所有敌方攻击均被防住，对仍存活且可选中的目标反击一次，基础伤害 47/56。
- 反击共用直气的翻腾动画与重击受击效果；一次演出、一批多目标攻击。原版攻击前后钩子和 `CreatureCmd.Damage` 处理力量、虚弱、易伤及活力，已有空手道批次逻辑只消耗一层。不生成、入堆或额外打出直气卡，保留原直气模型与所有内容标识。
- 保留原杀气的资格规则：奈落生命损失使反击失效，自伤和持续伤害不影响资格；重复打出不重置受伤记录，伤害取较高版本，不重复反击。反击开始前移除能力，避免反伤或死亡过程重复触发。

16 语言卡牌与能力说明同步更新；已有 AutoAnthony 公共组件同步删除柔术弃牌并改为直接反击。没有增加全局 Patch、第三方私有接口、存档键或对外 API。

## 验证

真实 stable 0.107.1 与 preview 0.111.0 程序集完成构建和完整产品行为契约。专项覆盖回合时点、意图出现/消失与下一轮意图、两名攻击者的一次伤害波、部分穿透的多段攻击、奈落吸收/溢出、缓冲、自伤、持续伤害、受伤后治疗、重复打出、升级、满手牌、目标先死亡、到期与重复钩子。新崩拳伤害、柔术无选牌无弃牌、事件的三层与角色限制均用实际模型核验。旧 1.0.20 工坊 DLL 在相同反击契约下失败，新包通过。

原有弃牌/Sly 单机和双进程 ENet 选择测试改用原版生存者，保留嵌套选择覆盖。新增联机测试通过原生队列让双方分别打出基础/升级杀气，再交换未完全格挡的玩家，验证各自资格、伤害和状态一致，不生成战斗卡。联机回合末钩子由测试夹具调用；不是两台完整渲染客户端的实战回合。

隔离后台 Windows 预览客户端仅加载 NinjaSlayer 与 RitsuLib。普通、快速、瞬间速度下，基础版/升级版各验证一次直气翻腾完成后，对两名锁定目标播放受击效果并结算，第三名新攻击意图敌人不受伤，资源只消费一次，角色收招归位。加上力量 3、活力 4、虚弱、易伤和空手道 3 后，每名目标实际受到 63/73 点伤害。

371 项逻辑测试、仓库和 16 语言本地化检查通过。发布以最终提交重新冻结并验证统一工坊包，回验记录另附；不创建 GitHub Release。未覆盖完整 stable 客户端、移动端、macOS/Linux 或两台完整渲染客户端，不将这些范围表述为通过。
