# 官网按卡牌规则合并版本

版本筛选只展示卡牌规则版本，后续无卡牌规则改动的发布并入上一组。此次 1.2.3 只修复沢渡事件手柄焦点，正式包导出的 16 种语言、全部模组卡牌字段与 1.2.2 逐项相同，归入 1.2.2。交叉防御在 1.2.2 改为跳过能力牌，影响实际牌序，因此 1.2.2 保留独立分组。

分组表为 `Website/content/card-version-groups.json`。不直接以目录 JSON 的字节差异判定规则变化，因为目录还包含构建版本、源码、DLL 哈希、卡图和翻译；也不把缺少历史目录的发布自动并入前版。

## 历史依据

0.2.6 是已有官网运行时目录的最早基线。0.2.7–0.2.11 为网站、演出、手里剑视觉及投递修复，归入该基线。依据各版冻结源码中的 `Workshop/change-note.md` 和现存 0.2.6／0.2.7／0.2.11 目录。0.2.12 新增沢渡砍刀，保留新组；0.2.13–0.2.15 的遗物、域名、预见说明与卡图更新并入 0.2.12。0.2.16、0.2.17 有明确卡牌数值及效果调整，分别保留。

0.3.0 的手里剑原生激发语义变化、0.3.1 的守势／从容调整、0.3.2 的卡池调整、0.3.4 的七项规则调整及 0.3.8 的 v1.17 卡牌改动分别保留。0.3.3 明确未调整普通卡牌规则，归入 0.3.2；0.3.5 的投递修改、0.3.6 的动态名称和音频、0.3.7 的三语文案归入 0.3.4。0.3.9 明确未调整卡牌规则，归入 0.3.8。依据 `release-0.3.3-20260926.md`、`release-034-20260928.md`、`release-036-20260929.md`、`release-037-20260929.md`、`release-038-20260930.md` 及各版冻结更新说明。

1.0.0–1.1.1 逐项对照 `Workshop/changelog-history.json` 中已核实的版本、源码和更新说明。1.0.0–1.0.2 并入 0.3.8；1.0.4 的更名并入 1.0.3；1.0.10 并入 1.0.9；1.0.14 的译名与演出修复并入 1.0.13；1.0.16–1.0.17 的语言、反馈界面更新并入 1.0.15；1.0.20 并入 1.0.19；1.0.22 的文案简化并入 1.0.21；仅改版本号的 1.1.0 并入 1.0.27。

1.0.12 虽然卡牌目录未变，但预见改为先洗空牌堆，影响卡牌机制，保留新组；1.0.18 的原生打击标签、1.0.23／1.0.24 的守势与交叉防御改动同样保留，即使未导出对应官网目录。1.2.0、1.2.1 各有明确卡牌调整，分别保留；依据对应 `release-1.2.x.md`。名称、卡图和翻译单独变化不拆分统计。

## 数据与验证

快照保留真实版本和原始分组，只增加版本到卡牌组的映射。卡牌统计、趋势、图表及战报使用同一选择规则；战斗测量仍检查采集时的版本。旧链接如 `?version=1.2.3` 自动归为 `1.2.2`，同组选中多次只计一次。未知或开发版本不推测归属。历史目录与玩家来信原样保留。

测试覆盖版本合并后的对局、胜负、抓取分母、战斗测量、跨组战斗排除、加权图表、重复选择、旧链接、其他筛选、全部版本总数及不改写原始数据。分组表测试要求所有已发布目录有且仅有一个归属，并检查缺少目录但有规则变化的版本仍独立。
