# 手里剑充能球槽位整改与本地验证

基线为 `25aea27233a3cdadb68f001045ada453f08ca570`，本地分支 `codex/shuriken-orb-slots`。
以下为最初本地开发候选的验证记录；用户随后授权与泽渡收尾修复一起发布 0.3.0。
干净候选及发布证据见 [事件收尾验证](sawatari-completion-validation-2026-09-22.md)。

## 已实现行为

- 其他角色使用原版队列顺序，手里剑不固定末格。原版非 Defect 的零槽生成会增加一个正常槽，库存耗尽后保留该槽；Defect 缩到零槽后仍遵循原版不自动补槽的行为。
- 忍者杀手的手里剑模型仍参与原生战斗钩子及联机枚举，但不占 `OrbQueue.Capacity`。可以同时拥有10个正常槽和一份专属库存；正常槽的增加、移除和满槽替换不会操作专属槽。
- 正常球维持原版相对顺序，专属球位于逻辑队列最后。队首、队尾激发均优先选择正常球；只有空正常槽时仍可激发手里剑。正常球生成、历史记录、等待、音效及钩子继续由原生命令执行。
- 每次原生激发发射当前全部库存，只有原版最终出队才清空。3层被双重／四重激发分别发射6／12次；Multi-Cast按原版X及升级处理，X为0且未升级时不消耗。打碎沿用原版循环，让每层发射两次后移除。
- 原生 `AfterOrbEvoked` 每次命令调用只派发一次；无星之夜和乘胜仍逐发结算。弃牌仍每张发射一次并扣一层，洗牌、月面宙反、地狱龙卷保留既定库存规则。无星之夜的批次上限及其卡面／Power文本未改。
- 专属槽清空后移除额外显示节点；其他角色留下正常空槽。悬停双重／四重／多重激发显示实际选中的球；打碎显示全部球。

删除了临时槽所有权／转移、替换预备标记和“多重激发只扣一层”的补丁。模型ID及 `shuriken_orb_state`／`StackCount` 保存标识保持；没有新增容量存档、运行存档迁移、全局调度器或独立充能球队列。目录及中英文充能球说明已同步，玩家卡牌数值、牌池和规格不变。
