# Ninja Slayer 当前牌池审计

> 当前基线：工作树最终卡池
> 范围：唯一注册的 Ninja Slayer 角色、初始牌组、奖励池及仍可见的衍生牌和先古牌。

## 结论

Ninja Slayer 初始与最大生命均为72。初始牌组为4张打击、5张防御和1张空手道直拳。普通奖励池共74张，严格分为20白、31蓝、23金，不再注册旧卡池，也不再提供恢复旧卡池的设置项。

龟壳是金色奖励牌。空手道直拳、茶道、直气、强·手里剑、终结、黑炎、死线和崩拳不进入奖励池；打击与防御也只属于初始牌组。崩拳、坐禅饮料和一心同体组成3张先古牌。退出当前池的牌保留原实现，但不再注册为当前奖励或特殊可见牌；出拳也保留实现但不再注册。

## 锁定例外

- 茶道仍为1费获得1点能量并消耗，移除保留，继续使用旧版茶道卡图。
- 初始遗物在每场战斗开始时触发茶道呼吸2。
- 先古初始遗物先将2张茶道加入手牌，再触发茶道呼吸2。
- 藏锋、舍念和飞刃轮转是蓝卡奖励；岚之拳是金卡奖励，出拳退出当前特殊牌区。
- 黑炎重拳沿用稳定ID `SatsubatsuRedesignV1`；阿拉巴马落沿用稳定ID `AlabamaDropRedesignV1` 并进入金卡奖励。
- 打击·打击只有一个有效模型，稳定ID为 `ChopStrikeRedesignV1`，采用原版粒子墙式回手语义。
- 强·手里剑是0费消耗Token，只有无星之夜的手里剑结算链会生成。
- 崩拳、坐禅饮料和一心同体继续作为3张先古牌。

## 机制边界

- 茶道呼吸不保存独立层数且只强化手牌中的茶道。手牌没有茶道时，无视其他牌堆已有茶道，当前触发先花费1点在手牌生成1张，再以剩余数值强化该牌。
- 茶道静息先结算茶道呼吸，再为持有者施加1层保留茶道。每层持续一个玩家回合，清理手牌前只让当时手牌中的茶道获得单回合保留。
- 空手道由持有者自身保存。每个合格攻击波次只触发一次，对同波次所有目标追加同一层数快照的伤害，结算后只变化1层。当前只有统一的 `CreatureCmd.Damage` 波次补丁负责触发，不存在第二条空手道伤害路径。
- 手里剑以可重复堆叠的专属充能球保存，忍者杀手基础球位为0。首次获得时由原版凝聚流程增加临时球位，库存归零后收回；没有库存时不显示空槽。
- 手里剑基础伤害为4，并按原版充能球规则接受集中增伤。拥有者通过 `CardCmd.Discard` 实际弃掉每张牌时从球位激发1次并失去1层；普通洗牌不触发。
- 飞刃轮转使拥有者洗牌时快照当前N层手里剑并激发N次，整条洗牌结算结束后只失去1层。普通释放激发1次并只失去1层；双重释放、四重释放和其他多重施放激发对应次数，但整次效果仍只失去1层。球位已满并被新充能球挤出时，手里剑逐层发射全部库存并移除整球。所有发射只播放球体高光、投掷、命中、受击和音效反馈，不模拟打出手里剑Token牌。
- 手里剑起防按每发所有结果的实际伤害与过量伤害获得格挡；飞刃席卷只强化下一次激发。无星之夜在一整条手里剑结算链中最多生成1张强·手里剑。
- 每张手中黑炎在持有者打出一张攻击牌后令所有存活敌人失去4点生命；多段和群攻仍按一张攻击牌触发一次。回合结束时持有者失去4点生命，所有存活敌人失去4点加烧烧烧增幅的生命，友军不受影响，随后只消耗该黑炎。
- 阿拉巴马落按当前空手道层数造成6N→8N伤害，跳过普通空手道追加伤害，随后清空空手道并加入3张晕眩。龙卷拳在X至少为4时，每段命中后立即给予1层易伤。
- 左重拳和右重拳只读取持有者自己的上一张已结算卡牌，记录跨回合保留；一饮一击只读取本回合由宿主弃牌命令产生的实际弃牌。
- 打击·打击与见切连打直接采用原版粒子墙的回手语义和中英文句式，不注册“复读”自定义关键词。
- 半月圆规踢的茶道选择上限等于手牌内实际可选茶道数，造成5→7群体伤害`1 + 2 × 消耗茶道数`次。
- 奈落形态将攻击牌费用改为0，打出后消耗并生成黑炎。一心同体直接获得30→40奈落生命。
- 地狱龙卷直接施加宿主原版 `SoarPower`，不定义同名或替代翱翔能力；其自有能力只负责下回合发射全部手里剑及升降表现。

## 静态验收

仓库校验器从 `RedesignV1Rules` 读取三档奖励清单，并与实际继承 `RedesignV1CommonCard`、`RedesignV1UncommonCard`、`RedesignV1RareCard` 的类集合比较。它同时检查：

- 20/31/23数量与74张唯一奖励牌；
- 10种特殊牌不进入奖励池且实现仍存在；
- 最终86种可见模型均有中英文标题与描述；
- 归档牌仍保留源码与功能，且不进入奖励或特殊可见清单；
- 奖励牌卡图存在且保持一对一；
- 唯一角色、72生命、初始牌组、遗物与设置边界符合当前设计。

实机平衡、长连击节奏与极端组合由玩家验证；本轮不以 SmokeDriver 代替实机结论。
