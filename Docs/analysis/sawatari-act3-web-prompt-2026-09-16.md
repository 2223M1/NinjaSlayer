# 第三层泽渡：供无记忆新对话独立评价的完整提示词

请担任《Slay the Spire 2》怪物与战斗设计审查者，独立评价 NinjaSlayer Mod 的第三层泽渡事件。你不需要本地文件或之前的聊天记录，相关资料已写在本文中。不要把设计者的愿望当作已经成立的结论，也不要为了支持或否定它而挑选案例。

请用中文给出明确判断、可复核的怪物数值计算和少量必要改动建议。不要实现代码，不要另行设计卡池。你的主要问题是：当前实现是否鼓励玩家合理、积极地归还大刀，并由此降低整场战损；其难度是否适合一个允许预热、可以放弃、奖励两件遗物的第三层额外挑战。

## 1. 资料边界与目标

- 快照日期 2026-09-16，Mod 源码提交 8c3cfa4。泽渡规则以此代码快照为准。只直接对比原版怪物，不使用任何职业卡池作评价依据。原版参照版本为 0.111.0，项目另支持 0.107.1；本文不声称两个原版版本内容完全相同。
- 主环境为单人 A10，并检查 A0 差异。A8 提高敌人生命等参数，A9 提高攻击等参数；A10 的直接新增规则是双 Boss，本文泽渡在 A9、A10 的自身数值相同。整局资源压力仍可能不同。
- 最终评价范围只包括泽渡与同版本原版第三幕怪物的血量、行动、攻击、成长、附加压力，以及事件的预热和奖励条件。**不分析忍者杀手卡池，也不分析原版五职业卡池。不要自行添加卡组、假设每回合输出或格挡，更不要据此模拟胜率和实际损血。**
- 设计目标一：当费用和运转充裕时，积极打出大刀归还泽渡，应有助于降低整场战损。
- 设计目标二：当费用或运转紧张时，允许先保留大刀，在缺防等关键回合改变意图。斩杀、手牌、攻防条件可以使不还刀更合理。目标不要求每次拿到刀都立即打出，也不要求每回合把所有刀还完。
- 设计目标三：挑战定位高于普通第三幕精英。首战有泽渡协助，玩家可以较低压力完成一定启动；评价决斗必须计入这一优势，也不能假设所有卡组都已完美启动。
- 只评价当前机制。若建议修改，先找少量数值能否解决问题，保持简单清楚。不要添加治疗牌，不要把“加复杂机制”作为默认答案。
- 没有本次 A10/A0 的实战胜率、损血分布或完整种子样本。下文是代码事实与可供计算的资料，不是实战测量结果。若需要额外规则才能判断某个极端组合，请明确列出缺口，不要补造规则。

## 2. 事件全过程与继承

事件要求队伍中有忍者杀手。第一、三层共用事件 ID 与已访问排除规则；第一层访问过会影响第三层可遇性。路由是在问号节点将符合条件的普通怪物遭遇替换为该事件，弱敌阶段之后的普通战斗才符合条件；首战不是精英。

首战仍是当前普通敌人，泽渡作为友方在每次玩家方回合开始时攻击一名敌人，A0 为 12×2，A10 为 14×2；他在协助阶段不投刀、不增长投刀力量。自动助攻会缩短首战，不能把首战当作无限安全的准备室。其伤害不是玩家免费选择何时结算的技能。

消灭普通敌人后可以拿普通战斗奖励离开，或者放弃这份奖励挑战泽渡。决斗获胜的标准奖励集合替换为两个原版 RelicReward，不是“普通卡牌、金币、药水奖励外再加两遗物”。奖励价值是选战理由，不能单凭两个遗物就推导敌人数值应该翻倍。

选择决斗后，移除友方泽渡，新建敌方泽渡：满生命、两把刀、零力量、没有待执行的强制投刀。玩家仍在同一个 CombatState 内；真实生命、能力和其他战斗资源、牌堆、消耗堆等不被整体重置。首战打出的持续能力、已积累的战斗资源与消耗记录等可以参与后续决斗；首战消耗掉的有限防御牌也不会自动回来。

转换通过原版额外回合通道结束当前玩家回合，再开始下一玩家回合，使泽渡不会抢先攻击。正常回合末与回合开始结算仍发生，临时力量、保留时限、格挡、回避等遵守原有生命周期，能量和抽牌按正常回合规则处理。不能把过渡描述为“冻结手牌原样开始”或“重新开一场全新战斗”。战斗开始遗物不因此再触发一次；回合开始效果会正常继续。

新敌人在过渡回合末结算前已加入战斗，因此已有的回合末自动出牌、充能球等可能先对新泽渡产生效果。若从“决斗第 1 个完整玩家回合”开始列账，应记录过渡后的实际敌人 HP 和玩家状态；假设敌人仍满血必须明确说明。本文统一用 T1、T2 等表示决斗中的相对玩家回合，不把它们当作整个 CombatState 的回合编号。

## 3. 泽渡的完整核心规则

### 数值

| 项目 | A0 | A10 |
|---|---:|---:|
| 最大生命 H | 252 | 278 |
| 刀攻击基础单段伤害 D | 12 | 14 |
| 无刀竹击基础单段伤害 b | 2 | 2 |
| 竹击段数 | 4 | 4 |
| 每次投刀后的永久力量增长 g | 3 | 3 |
| 初始刀数 W | 2 | 2 |
| 初始力量 S | 0 | 0 |

A0–A7 生命 252，A8 起 278；刀伤 A0–A8 为 12，A9 起 14。当前泽渡没有自带人工制品、格挡、阶段伤害上限或抗爆发能力。

### 行动选择及生效时点

除了刀数 W 与力量 S，必须记录布尔状态 F，表示“下一次有刀行动必须投刀”。初始 F=false。

```text
选意图：
  W == 0                 -> 竹击，(2 + S) 伤害，4 次
  W >= 1 且 (F 或 W==1)   -> 投刀，(D + S) 伤害，1 次
  W == 2 且 F==false      -> 双刀，(D + S) 伤害，2 次

双刀执行后：
  W 不变，S 不变，F=true。

投刀执行：
  移除泽渡的一把刀，F=false。
  按投刀之前的 S 结算攻击。
  若泽渡仍活着，S += 3。
  若目标玩家仍活着，将一张“大刀”生成到其手牌。

竹击执行后：
  W、S 不变。按当前状态继续选择行动。

大刀对当前第三层泽渡打出并结算伤害后：
  若泽渡存活且 W<2，W += 1，并立即重新选择意图。
  不清除 F，不减少 S。
  若已经两刀或泽渡死亡，不增加刀数。
```

以上伤害公式假设无其他属性与减伤。原版力量逐段作用，虚弱、易伤等再按宿主实际规则结算。不额外加入忍者杀手的空手道等 Mod 规则。

完全格挡或回避投刀，也不会阻止力量增长与大刀生成。若反伤在攻击中杀死敌人、玩家死亡或其他效果中断行动，按存活条件与实际命中顺序截断，不能继续结算假想完整回合。双刀之后的强制投刀不能只因还刀被替换成另一轮双刀。

### 玩家得到的大刀

- 2 费 Token **攻击牌**，保留、消耗；基础造成 12 伤害，不可升级。它不是状态牌，投刀意图显示状态图标不改变牌的实际类型。
- 只有以当前第三层泽渡为目标实际打出，才在伤害结算后归还一把刀。攻击其他目标、弃置、直接消耗、变换都不还刀。
- 遵守普通攻击的力量、虚弱、易伤、活力、攻击出牌触发等原版规则；临时增益的消耗及其对后续牌的影响也要计入。
- 复制品、重复打出和自动打出都可以归还刀；每次实际出牌独立处理，敌方刀数最多 2。没有额外武器身份或“两把物理刀”的全局守恒限制。不要假定复制品是假刀、不归还。
- 原版自动打出通常不支付该牌的手动能量费用；安排顶牌、复制、赋予奇巧本身有成本，且两次出牌可能把不同意图连续切换。
- 手牌上限 10。投刀生成到手牌，满手时转入弃牌堆。生成或直接移入手牌不算抽牌；正常持有保留大刀主要占手牌容量。刀进入弃牌堆、后续被洗回时，才会占用实际抽牌。
- 使用后遵守消耗去向。回牌顶效果若仅修改原本进入弃牌堆的牌，就不能覆盖其消耗去向。不能将仅能取弃牌堆的效果当作可从消耗堆取刀。

机甲骑士加入的灼伤是无法打出的状态牌；回合末仍在手中时每张造成 2 点可被格挡的伤害。它不是生成时立刻造成 2 点损血，因此不能把每次喷火简单加成固定 8 点实际损血。

三骑士的合计 HP 为 276／294，但不能直接把这个数字当成一个敌人的等效耐久。Hex 给尚无附着的牌施加 Hexed，使受影响牌在该 Power 存在时具有虚无，来源死亡后解除。Dampen 暂时降级玩家已有升级牌，来源被消灭后恢复。这些是实质的运转干扰，泽渡没有同样的原生干扰。

可选挑战参照为同幕事件“战痕累累的训练假人” BattlewornDummy。其 V3 对手 BattleFriendV3 为 300 HP，不攻击，3 次敌方回合结束后逃离；玩家须在限时内击败，奖励 1 遗物。V1 奖励药水，V2 随机升级 2 牌。它适合参照可选挑战的输出门槛和奖励，不能作为同等承伤威胁的精英。源码中存在但 IsAllowed=false 的 WarHistorianRepy 不作为当前正常可遇挑战的证据。

## 5. 评价标准与计算边界

目标是有意义、可理解的战斗选择。还刀应当通过改变行动和资源分配产生作用；费用充裕时鼓励积极利用机制，费用紧张时允许择机出手。目标不是每次拿到刀都立即打出、每次都还完，也不要求所有不还刀选择都遭到惩罚。

关注五件事：能否用简单规则理解选择；还刀会怎样改变当前及后续压力；是否存在容易永久回避互动的稳定状态；机制是否来得及被体验；计入首战预热后，挑战是否有高于普通精英的依据。数值实验优先于复杂的新机制。评价标准不包含某个职业缺防、某张输出牌过强或特定卡组是否能无限循环。

本轮只计算没有额外属性与减伤时的怪物攻击轨迹，以及大刀明确的 2 费、12 伤害。可以指出能量占用、手牌容量、未来成长和斩杀时点是影响战损的因素，但不要擅自为这些因素赋予固定数值。

必须区分四种陈述：

- 实现事实：正文中的规则与数值。
- 计算结果：在列明假设下，按状态机得到的刀数、力量、攻击总额和还刀成本。
- 设计判断：对选择质量、节奏、强度定位、改动必要性的判断。
- 待实测事项：整场实际损血、击杀回合、玩家决策分布、平均战损与胜率。没有这些数据时不伪造，也不要绕回卡池模型推测。

比较原版怪物时，不能只按生命或攻击累计数排名。机甲骑士的 3 人工制品、15 格挡、4 灼伤与周期性成长，灵魂枢纽的虚弱易伤，三骑士的多人同时施压和干扰，都应单列。裸伤表若未算灵魂枢纽施加易伤后的增幅，就必须标注，不能冒充实际输出。随机怪物不编造一条唯一标准行动序列；可以直接列动作池与确定开场。本轮不把每种负面效果强行折算成若干伤害。
