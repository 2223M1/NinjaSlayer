# 忍者杀手 · 卡牌分类参考

## 当前卡池

Ninja Slayer 是唯一注册角色，初始与最大生命均为72。初始牌组为4张打击、4张防御、1张空手道直拳、1张预判。

当前产品共92个卡牌模型，普通奖励池80张，分为20白、35蓝、25金。其余12张为初始牌、Token、状态牌与先古牌。红卡及其不再使用的能力、独占资源只保留在开发机 `.local-reference/legacy/`，不编译、不注册、不打包。

本次不支持旧运行存档，不迁移旧模型ID。升级前结束旧局，或备份原文件后新开局；不支持的存档读取失败时保留原文件。

## 核心规则

- 手选弃牌使用原版猎手卡池的选择和批量弃牌语义。每张实际弃牌分别触发弃牌效果，整批弃牌结束后依次自动打出奇巧牌。预见同样如此，只是选择来源为抽牌堆；嵌套预见独立结算。预判只按自己的预见实际弃牌数获得格挡。预见改为消耗时，不产生弃牌事件或奇巧自动打出。
- 茶道是1费、消耗的状态牌，保留现有能量累积。茶道呼吸只强化手牌中的茶道；没有茶道时用第一点呼吸生成一张，再用剩余呼吸强化。初始遗物每场战斗呼吸2；先古升级版先生成2张茶道再呼吸2。仅开局遗物生成的茶道获得保留，后续新生成的茶道没有保留；原版复制和其他保留效果照常生效。
- 茶道静息在回合末清理手牌前保留当时手中的茶道，包含后来抽到或生成的茶道，每层持续一个玩家回合。畷饮每次施放独立持续3次回合开始；升级立即额外呼吸1。聚气读取所选茶道的累积能量值。
- 空手道由攻击者持有，每段攻击触发一次；群攻共用该段触发前层数，结算后变化1层。追加伤害不受力量、虚弱和易伤影响。Chop连锁按任意生物每次实际层数变化计数，不按层数计数；直接清空也算一次，余数跨回合保留。生成的Chop附带消耗并服从消耗去向。
- 岚之拳手动打出要求抽牌堆、手牌、弃牌堆合计至少3张茶道；自动打出遵循原版规则。先消耗这三个牌堆中的全部茶道，再攻击4次，每次4→6加消耗堆每张茶道的6点，包含刚消耗的茶道。强·Chop每回合每打出3张攻击回手。
- 手里剑是一项可叠层资源，使用充能球系统接受原版激发交互。基础栏位为0，首次获得时临时增加1个栏位，库存归零后回收，不影响其他充能球。基础单发伤害4并接受集中。每张实际弃牌激发一次、扣一层，随机选择存活敌人；回合末清理、消耗和直接移牌不算弃牌。
- 普通洗牌不触发手里剑。飞刃轮转按洗牌时N层库存激发N次，整条效果扣一层；双重、四重等多重激发按实际次数发射，整条效果扣一层。满栏替换按剩余库存发射后移除旧球。弃刃成锋每张实际弃牌补充一次库存，与宿主回调顺序无关。
- 飞刃席卷持续整个当前回合，使每次激发攻击所有敌人。手里剑起防按该回合手里剑实际伤害获得格挡，先获得库存和能力再弃牌。藏锋给予永久集中；强·手里剑也接受集中增伤。
- 无星之夜保留当前卡面及每条效果链最多生成一张强·手里剑的规则。一次实际弃牌、一次飞刃轮转洗牌、一次多重激发、一次满栏替换、一次地狱龙卷齐射分别是独立链，群攻不按目标数重复生成。
- 地狱龙卷使用原版翱翔，翻倍库存，下回合开始激发并清空全部库存。维持当前升空、旋转、下落和回到站姿的演出。
- Wasssssshoi!只统计攻击与手里剑对敌人的正伤害，包括被格挡的部分；每次对每名目标的伤害分别触发。独立空手道追加伤害、黑炎、自伤和其他伤害不触发。临时力量、集中在回合结束时扣回，保留其他来源的永久属性。
- 黑炎在手牌中时，每打出一张攻击牌使所有存活敌人失去4点加烧烧烧增幅的生命，不按攻击段数重复。回合结束时自身失去4点，敌人失去4点加增幅，然后消耗。回回回是持续能力，每张黑炎实际消耗时获得4→6奈落生命。
- 大·受身快照抽牌堆、手牌和弃牌堆中的状态，逐张尝试原生自动打出并消耗；不可打出的直接消耗，已消耗的不重复消耗，不递归处理新生成状态，最后获得1缓冲。黑炎恢复只消耗转化后手牌中的状态，每张实际消耗恢复2生命。
- 忍耐检查整个当前回合是否打出攻击，包含它自身打出之前的攻击。状态抽牌在实际抽到状态后继续抽牌，生成和直接移入手牌不触发。
- 打击·打击服从原版回手规则，消耗等去向优先；龙卷拳在X至少4时逐段命中后施加易伤。左右重拳只读取持有者上一张已完成的牌，跨回合保留。
- 奈落形态使攻击免费、打出后消耗并向抽牌堆加入黑炎，只有打出奈落形态才化身半奈落。一心同体只给予奈落生命。奈落事件准入牌为黑炎起甲、黑炎重拳、深渊之力、氮气加速、燃烧殆尽、烧烧烧、奈落形态、回回回、黑炎恢复、一心同体；事件遗物每场战斗开始给予奈落形态能力并化身全奈落。ZBR只给予12奈落生命。
- 运行存档使用宿主的战斗重开规则，不保存退出瞬间的充能球队列和临时栏位。
