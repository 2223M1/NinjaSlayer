# 忍者杀手 · 卡牌分类参考

## 当前卡池

Ninja Slayer 是唯一注册角色，初始与最大生命均为80。初始牌组为4张打击、4张防御、1张直拳、1张料敌。

当前产品共93个卡牌模型，普通奖励池80张，分为20白、35蓝、25金。其余13张为初始牌、Token、状态牌与先古牌。红卡及其不再使用的能力、独占资源只保留在开发机 `.local-reference/legacy/`，不编译、不注册、不打包。

本次不支持旧运行存档，不迁移旧模型ID。升级前结束旧局，或备份原文件后新开局；不支持的存档读取失败时保留原文件。

## 核心规则

- 卡面伤害和格挡数字使用原版动态预览与增减染色，随力量、敏捷、虚弱、易伤等实际适用效果变化。掌打、动静相生和料敌同样如此；岚之拳显示本场战斗累计增长后的单次伤害。黑炎的固定生命损失及公式中的每张牌增量不受力量影响。
- 手选弃牌使用原版猎手卡池的选择和批量弃牌语义。每张实际弃牌分别触发弃牌效果，整批弃牌结束后依次自动打出奇巧牌。预见同样如此，选择来源为抽牌堆；先把整批选中牌移出可抽范围，再执行原生批量弃牌；嵌套预见独立结算。料敌只按自己的预见实际弃牌数获得格挡。预见改为消耗时，不产生弃牌事件或奇巧自动打出。
- 预见开始时若抽牌堆为空，先通过原生洗牌将弃牌堆洗入抽牌堆，等待洗牌效果完成后查看新牌堆顶部。抽牌堆非空但数量不足时不补洗；两堆皆空或预见数量不为正时不打开选牌。预见关键词省略奇巧提示句，弃牌与奇巧的实际结算保留。Mother UNIX访问密钥在持有者每回合开始抽牌前预见3，包括首回合；预见及其引发的奇巧结算完成后，继续正常回合抽牌。
- 茶道是1费、消耗的状态牌，保留现有能量累积。茶道呼吸只强化手牌中的茶道；没有茶道时用第一点呼吸生成一张，再用剩余呼吸强化。初始遗物茶道呼吸每场战斗呼吸2，接下来的1回合保留所有手牌茶道；先古升级版茶道呼吸·真髓先生成2张茶道再呼吸2，首回合所有手牌茶道获得单回合保留，包含随后生成的茶道。原版复制和其他保留效果照常生效。
- 守静在回合末清理手牌前保留当时手中的茶道，包含后来抽到或生成的茶道，每层持续一个玩家回合。啜饮每次施放独立持续3次回合开始；升级立即额外呼吸1。聚气读取所选茶道的累积能量值。
- 空手道说明不再附加“群攻只失去1层”，实际消耗规则不变。
- 空手道由攻击者持有，每段攻击触发一次；群攻共用该段触发前层数，结算后变化1层。追加伤害不受力量、虚弱和易伤影响。Chop连锁已退役；地狱·Chop具有虚无，每次抽到时将一张保留当前升级状态的复制品加入手牌。生成不视作抽牌，不递归复制。
- 岚之拳造成5→6点伤害4次。每次己方回合结束时，本场战斗中的伤害增加2→3，并具有原生消耗。岚之拳、龙回旋踢与掌打、对空砰砰拳、龙卷拳统一使用单条原生多段攻击指令：活力加成覆盖整次攻击的所有段及目标，攻击结束后消耗一次；额外段数钩子只执行一次。地狱·Chop不再按攻击次数回手。
- 手里剑是一项可叠层资源，使用原版充能球模型与激发回调。忍者杀手使用独立专属槽，不占正常槽位容量及10槽上限；没有正常槽位时生成普通球，按原版非Defect规则增加1个正常槽。正常槽增减及满槽替换不影响专属槽。其他角色的手里剑完全按原版队列排列、替换及缩槽，正常槽不会随库存耗尽回收。基础单发伤害6并接受集中。每张实际弃牌发射一次、扣一层，随机选择存活敌人；回合末清理、消耗和直接移牌不算弃牌。
- 忍者杀手的队首／队尾原生激发均优先选择正常球，仅剩手里剑时才激发专属槽；空正常槽不阻止回退。每次原生激发发射当前全部库存，最后一次原生移除清空整球。3层手里剑被双重／四重激发分别发射6／12次；打碎使每个球激发两次，手里剑各层也发射两次。普通洗牌不触发手里剑。飞刃轮转仍按洗牌时N层库存发射N次，然后失去2→1层，不足扣至0。伺机备刃每次有效预见结束后获得一层手里剑，零张弃牌也触发；没有看见任何牌时不触发。
- 飞刃席卷持续整个当前回合，使每次激发攻击所有敌人。飞刃屏障获得8→11格挡，本回合获得过手里剑则再获得一次相同格挡，库存清空不清除资格。藏锋给予永久集中；未记录快照的强·手里剑接受集中增伤。
- 无星之夜每次成功获得正数手里剑库存时生成一张强·手里剑，一次获得多层仍只生成一张，补充已有库存也触发。获得时锁定含集中的单发伤害，之后力量、虚弱、易伤按普通攻击计算，不再次增加集中。升级无星之夜获得固有；强·手里剑自身升级增加4伤害。守势在场上任意角色的空手道触发时获得1→2点格挡，多份能力收益叠加。
- 强·手里剑基础及升级均具有保留和消耗，使用原版小刀的投掷与命中命令顺序，复用手里剑动画，并保留模组快速出牌加速。瞄准与易伤分别乘算，通常合计2.25倍伤害；完成全部修正后沿用原版取整，预览与实伤一致。
- 撒菱直接给予原生荆棘，持续本场战斗；与其他来源正常叠加，不设置到期状态。
- 修行在正常抽牌后按每次打出的实例依次获得空手道并手选弃一张，弃牌沿用原生奇巧结算。
- 地狱龙卷使用原版翱翔，翻倍库存，下回合开始激发并清空全部库存。维持当前升空、旋转、下落和回到站姿的演出。
- 乘胜仅统计充能球手里剑对敌人的正伤害，包含被格挡部分；每次对每名目标分别给予本回合2→3力量。普通攻击、强·手里剑、空手道、黑炎及自伤不触发，回合结束扣回临时力量。
- 每次攻击出牌开始时确定手牌中的黑炎；攻击结束后，依手牌快照顺序逐张结算其中仍在手牌的黑炎；每张各使所有有效敌人失去4＋当前烈焰增幅的生命，并在轮到自身时闪亮，不按攻击段数重复。BS1260踢等在本次攻击期间生成的黑炎从下一次实际攻击出牌才开始触发；重复打出逐次重新确定。每张独立伤害播放一次原版灼伤音效；每次结算后重新检查战斗状态和有效目标，战斗结束则停止后续黑炎。回合末沿用原版灼伤的状态牌结算流程，逐张进入结算区、播放一次灼伤音效、结算自身4点及敌人4点加增幅的生命损失，再按虚无消耗；击杀最后敌人的当前黑炎仍完成自伤，宿主确认结束后不再处理后续黑炎。仍无视格挡，保留奈落生命保护。噬火是持续能力，持有者每消耗一张牌时获得2→3奈落生命，包括虚无消耗；生成、抽取、弃置及移动已有牌不触发，他人消耗不触发。
- 大·受身快照抽牌堆、手牌和弃牌堆中的状态，逐张尝试原生自动打出并消耗；不可打出的直接消耗，已消耗的不重复消耗，不递归处理新生成状态，最后获得1缓冲。浴火选择1张手牌变化为黑炎，本回合每触发一次黑炎获得2→3奈落生命；手牌攻击触发、回合结束和奈落形态的黑炎均计入，每次按触发结算一次，不按敌人数计数，获得的奈落生命可抵挡该次回合结束黑炎的自伤。
- 连打先通过原生固定目标三段攻击结算伤害，再获得空手道；不再有回合结束奖励。转机在持有者每生成一张状态牌时抽1→2张牌，按原生生成者归属判断；目标牌堆及满手溢出不影响触发。抽取、移动已有状态牌、他人或无生成者的状态牌不触发。
- 半月圆规踢必须有手牌茶道才可打出，每次消耗1张；单张实体伤害在本回合叠加翻倍，回合结束恢复，回手不覆盖原生消耗和临时复制品移除。
- Strike·打击在伤害与预见后生成同升级状态的新实体，原牌消耗；龙卷拳解析X后攻击X次，X至少4则每次伤害增加4→6，整次使用一个原生多段攻击命令。低空上勾拳读取持有者上一张已完成的牌，跨回合保留；若为攻击牌，命中后给予虚弱与易伤。破势一击造成6→9点伤害，给予2→3层瞄准。瞄准使受到的手里剑伤害增加50%，随机手里剑优先选择被瞄准的存活敌人；多个瞄准目标之间沿用原版战斗随机数。敌方回合结束时减少1层，手里剑命中不消耗层数。强·手里剑同样获得50%增伤，手动选择目标保持不变。图标使用原版精准。
- 普通打击、Chop打击、Strike·打击均具有原生 `CardTag.Strike`，基础／升级与生成实体一致。打击木偶及假打击木偶分别按原生规则增伤3及1；完美打击按战斗卡堆中的该类牌数量计算伤害。非打击攻击牌不加入该分类，且非基础打击不会因此被判为基础打击／防御。
- 奈落形态卡不修改攻击费用或去向，也不生成黑炎。每打出一张攻击牌，每层奈落形态分别对所有敌人触发一次黑炎伤害，每次为4＋当前烈焰增幅；相当于每层额外一张只在攻击后触发的黑炎，不创建卡牌、不参与回合末自伤或消耗收益。仅打出奈落形态进入半奈落。事件遗物奈落解放进入全奈落，每个己方回合开始加入1张黑炎，不提供攻击后独立黑炎；同时拥有遗物与卡牌能力时分别生效。事件既有准入卡保留；ZBR仍只给予12奈落生命。
- 一心同体获得7→10奈落生命；每层一心同体使每点奈落生命计入1点空手道攻击触发伤害和显示层数，随生命增减同步更新。每次触发优先消耗1点奈落生命，耗尽后才消耗基础空手道；群攻一波一次、多段分别消耗。阿拉巴马落、倍劲、坚壁等仍按实际获得的空手道计算，基础空手道不抵挡伤害。每次打出均获得7→10点奈落生命并叠加1层换算倍率（两层时每点奈落生命计入2点空手道），触发始终只消耗1点奈落生命；保留形态演出、3费和虚无。
- 运行存档使用宿主的战斗重开规则，不保存退出瞬间的充能球队列和临时栏位。

- 奈落生命等同临时生命：伤害先经无实体等伤害修正与格挡，再扣奈落生命，溢出部分才进入缓冲、钨合金棍等生命损失处理。奈落生命吸收不算真实掉血，不触发治疗或百年积木／妖刀碎片；不破坏杀气·直气的无伤资格，也不触发暗忍的掉血偷牌。跨回合保留，可超过生命上限，战斗结束时清空。精神的棉被每个己方回合开始获得2奈落生命。奈落生命以叠在血条右端的紫色Temp HP心形图标与独立白色数值显示；爱心使用火焰VFX外焰及火星同款紫色（#FF31FF），血条保持白色描边；不延长血条、不改变真实生命数字或格挡位置。
- 月面宙反1→0费，两版保留；当前每层手里剑发射两次后清空，不补充库存。螺旋回转跳先对所有敌人造成8→12伤害，再激发并清空手里剑一次。飞刃轮转按洗牌前库存逐发激发，再扣2→1层，不足扣至0。
- 小季、沢渡 · 佛雷斯特、由佳乃及折纸飞弹造成的伤害不触发蜂群反应向主人塞状态牌；保持真实攻击者，不转移伤害来源。荆棘、反射和火焰屏障仍针对实际攻击者。本人、原版Osty及其他模组宠物的规则保持。

- 入定基础版和升级版均有虚无；像原版幻影之刃一样，使现有及后来进入战斗的茶道获得真实保留，仅影响本场战斗。审势获得5→7拉伸，再预见4→5，不赋予保留。
- 谋定使预见中未选走的牌获得永久奇巧，包括选择消耗的预见；在本次选牌确定后、弃牌结算前处理原始快照。从容每张实际弃牌获得2格挡，升级获得固有；使用Unpowered语义。
- 长息下个己方回合开始呼吸2X→2X+1，X按打出时的原生修正值确定。

## 条件发光与保留规则

保留原生条件发光；飞刃屏障检查本回合获得过手里剑。谋定不再具有旧处决条件发光。直气本身没有条件，不发光。

杀气·直气从首次生效开始记录敌方攻击造成的真实生命损失，自伤及持续伤害不影响资格。己方回合末锁定具有攻击意图的敌人，敌方回合末无伤则对仍存活且可选中的目标反击。每次打出增加1层，层数表示本回合反击次数；每次反击各执行一次直气演出和一批攻击伤害，力量、虚弱、易伤、活力与空手道分别沿用原版攻击结算。敌方回合末无论是否满足条件都清空层数，不带到下一回合。重复打出不重置受伤记录，每次反击伤害取本回合已打出版本的较高值；不生成或打出直气卡。

对空砰砰拳计数值为正的力量、敏捷、活力、空手道、集中、人工制品、缓冲、无实体、荆棘、覆甲、再生、回避、奈落生命、拉伸，每种一次。卡面和打出共用原生CalculatedVar显示实际命中次数。

奈落事件各阶段的“令其闭嘴”均可选择并永久移除牌组中的一张牌，然后结束事件。使用原版删牌选择界面与不可移除卡牌规则。

回避：每层回避一个敌人本回合的整次行动中的所有攻击，包括多段攻击和同一行动内的多次攻击结算；该敌人行动结束后消耗一层，不攻击则不消耗。被回避的攻击不扣生命或格挡。未用完的回避仍在自己的下个回合开始时移除。

投石车摔、旧飞刃屏障Power及已退役流程仅留本地参考，不进入编译、注册和发布包。初始及先古初始遗物均使用首回合单回合茶道保留。战局洞见、茶道护身和KarateScry已归档。

## 沢渡事件状态牌

- 砍刀（`Machete`）：2费 Token 攻击，保留、消耗，不可升级。造成12点伤害，使用原生动态伤害预览与斩击命中音效、特效；以本场沢渡为目标打出后补回一把砍刀，最多两把。可以攻击其他敌人，但不还刀。弃牌、直接消耗或变换不还刀；复制牌及重复打出仍可还刀。仅由事件产生，不进入普通奖励池与随机生成。
