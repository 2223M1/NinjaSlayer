# 忍者杀手 · 卡牌分类参考

## 当前卡池

Ninja Slayer 是唯一注册角色，初始与最大生命均为72。初始牌组为4张打击、4张防御、1张直拳、1张预判。

当前产品共92个卡牌模型，普通奖励池80张，分为20白、35蓝、25金。其余12张为初始牌、Token、状态牌与先古牌。红卡及其不再使用的能力、独占资源只保留在开发机 `.local-reference/legacy/`，不编译、不注册、不打包。

本次不支持旧运行存档，不迁移旧模型ID。升级前结束旧局，或备份原文件后新开局；不支持的存档读取失败时保留原文件。

## 核心规则

- 手选弃牌使用原版猎手卡池的选择和批量弃牌语义。每张实际弃牌分别触发弃牌效果，整批弃牌结束后依次自动打出奇巧牌。预见同样如此，只是选择来源为抽牌堆；嵌套预见独立结算。预判只按自己的预见实际弃牌数获得格挡。预见改为消耗时，不产生弃牌事件或奇巧自动打出。
- 茶道是1费、消耗的状态牌，保留现有能量累积。茶道呼吸只强化手牌中的茶道；没有茶道时用第一点呼吸生成一张，再用剩余呼吸强化。初始遗物茶道呼吸法每场战斗呼吸2，接下来的1回合保留所有手牌茶道；先古升级版茶道呼吸法·真髓先生成2张永久保留的茶道再呼吸2，后续生成的茶道不继承该关键词。原版复制和其他保留效果照常生效。
- 守静在回合末清理手牌前保留当时手中的茶道，包含后来抽到或生成的茶道，每层持续一个玩家回合。啜饮每次施放独立持续3次回合开始；升级立即额外呼吸1。聚气读取所选茶道的累积能量值。
- 空手道由攻击者持有，每段攻击触发一次；群攻共用该段触发前层数，结算后变化1层。追加伤害不受力量、虚弱和易伤影响。Chop连锁及其生成流程已退役；地狱Chop按本回合3张其他攻击牌回手，排除自身。
- 岚之拳无茶道数量门槛；先消耗抽牌堆、手牌和弃牌堆中的全部茶道，再攻击4次，每次4→6加消耗堆每张茶道的4→6点。地狱·Chop每回合每打出3张攻击回手。
- 手里剑是一项可叠层资源，使用充能球系统接受原版激发交互。基础栏位为0，首次获得时临时增加1个栏位，库存归零后回收，不影响其他充能球。基础单发伤害6并接受集中。每张实际弃牌激发一次、扣一层，随机选择存活敌人；回合末清理、消耗和直接移牌不算弃牌。
- 普通洗牌不触发手里剑。飞刃轮转按洗牌时N层库存激发N次，然后失去3→1层，不足扣至0；双重、四重等多重激发按实际次数发射，整条效果扣一层。满栏替换按剩余库存发射后移除旧球。弃刃成锋每次有效预见结束后获得一层手里剑，零张弃牌也触发；没有看见任何牌时不触发。
- 飞刃席卷持续整个当前回合，使每次激发攻击所有敌人。飞刃屏障获得8→11格挡，本回合已激发过手里剑则再获得一次相同格挡；无星之夜转化也计作激发。藏锋给予永久集中；强·手里剑也接受集中增伤。
- 无星之夜将每一发手里剑替换为一张同伤害强·手里剑，不直接造成伤害；群攻的一发仍只生成一张。转化时锁定集中加成，之后力量、虚弱、易伤按攻击牌规则计算，不再次增加集中。升级无星之夜获得保留；强·手里剑自身升级增加4伤害。
- 地狱龙卷使用原版翱翔，翻倍库存，下回合开始激发并清空全部库存。维持当前升空、旋转、下落和回到站姿的演出。
- 乘胜只统计攻击与手里剑对敌人的正伤害，包括被格挡的部分；每次对每名目标的伤害分别触发。独立空手道追加伤害、黑炎、自伤和其他伤害不触发。临时力量、集中在回合结束时扣回，保留其他来源的永久属性。
- 每次攻击出牌开始时确定手牌中的黑炎；攻击结束后，将其中仍在手牌的黑炎合并为一次伤害，使所有存活敌人失去4×黑炎张数＋一次烈焰增幅的生命，参与的黑炎同时闪亮，不按攻击段数重复。BS1260踢等在本次攻击期间生成的黑炎从下一次实际攻击出牌才开始触发；重复打出逐次重新确定。每次合并伤害播放一次原版灼伤音效。回合末沿用原版灼伤的状态牌结算流程，逐张进入结算区、播放一次灼伤音效、结算自身4点及敌人4点加增幅的生命损失，再按虚无消耗；仍无视格挡，保留奈落生命和一心同体保护。噬火是持续能力，每张黑炎实际消耗时获得3→5奈落生命。
- 大·受身快照抽牌堆、手牌和弃牌堆中的状态，逐张尝试原生自动打出并消耗；不可打出的直接消耗，已消耗的不重复消耗，不递归处理新生成状态，最后获得1缓冲。浴火将1张手牌变化为黑炎，本回合每打出1张攻击获得2→3奈落生命。
- 忍耐检查整个当前回合是否打出攻击，包含它自身打出之前的攻击。韧性在实际抽到状态后继续抽牌，生成和直接移入手牌不触发。
- 打击·打击服从原版回手规则，消耗等去向优先；龙卷拳在X至少4时逐段命中后施加易伤。左·上勾拳与右·上勾拳只读取持有者上一张已完成的牌，跨回合保留。
- 奈落形态不再修改攻击费用或去向，也不生成黑炎。每张攻击额外对所有敌人造成一次黑炎伤害，数值为4×奈落层数＋烈焰增幅；手牌黑炎合并伤害并同时使用原生手牌闪亮反馈；奈落触发与手牌黑炎分别结算。仅打出奈落形态进入半奈落，事件遗物给予相同能力并进入全奈落。事件既有准入卡保留；ZBR仍只给予12奈落生命。
- 一心同体免疫黑炎自身自伤，每次正数茶道呼吸效果获得3→4空手道，不乘呼吸量和茶道张数；重复能力叠加收益。
- 运行存档使用宿主的战斗重开规则，不保存退出瞬间的充能球队列和临时栏位。

- 奈落生命在格挡、缓冲和原版减伤之后吸收最终生命伤害，剩余伤害才扣真实生命，不触发治疗。精神的棉被每个己方回合开始获得3奈落生命。
- 月面宙反先激发并清空原库存，再获得1→2层；飞刃轮转按洗牌前库存逐发激发，再扣3→1层，不足扣至0。

- 入定像原版幻影之刃一样，使现有及后来进入战斗的茶道获得真实保留；玛卡古像响指一样选择一张尚无保留的手牌赋予词条。均只影响本场战斗。
- 制定计划使预见中未选走的牌获得永久奇巧，包括选择消耗的预见；在本次选牌确定后、弃牌结算前处理原始快照。战局洞见每张能力独立累计3→2张弃牌后抽1张，余数跨回合；从容每张实际弃牌获得2→3格挡。
- 长息下个己方回合开始呼吸2X→2X+1，X按打出时的原生修正值确定。

## 条件发光与保留规则

保留原生条件发光；飞刃屏障检查本回合手里剑激发，茶道护身检查本回合实际消耗茶道。制定计划不再具有旧处决条件发光。直气本身没有条件，不发光。

杀气仅更新卡面短文案及9→12格挡，实际仍从第一次生效开始记录所有伤害，奈落吸收也算受伤；回合末锁定攻击意图，下回合开始符合条件生成一张直气。重复打出不叠加、不重置受伤记录，任一升级版本使奖励升级。

对空砰砰拳只计数值为正的力量、敏捷、活力、空手道、集中、人工制品、缓冲、无实体、荆棘、覆甲、再生、回避，每种一次。卡面和打出共用原生CalculatedVar显示实际命中次数。

投石车摔、旧飞刃屏障Power及已退役流程仅留本地参考，不进入编译、注册和发布包。初始及先古初始遗物保持0.2.2规则。
