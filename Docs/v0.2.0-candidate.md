# 0.2.0 local candidate

This candidate implements the edited v1.5 board and subsequent confirmed rules.
GitHub push/merge and Workshop upload are on hold while the user edits wording.
The v1.6 board and local universal package are review artifacts, not a release.

## Gameplay and ownership

- Naraku Life absorbs final HP loss in `Creature.LoseHpInternal`, after native
  block, Buffer and damage modifiers and before the native lethal flag. It no
  longer heals damage back. Direct death commands retain their native behavior.
- Cancelled native `NCardTransformShineVfx` instances are freed on exit. A real
  stable-game reproduction showed an opaque overlay surviving card-pool reuse;
  the same scenario renders normally with cleanup. Normal transforms still use
  the native animation. No timer, material reset or alternate card renderer was
  added. Narrator's unrelated `StartFadeOut` error is not treated as its cause.
- Starless replaces each shot with one damage-snapshot token. Native card copies
  and RitsuLib saved model data preserve that snapshot; later Focus is excluded,
  while native attack modifiers remain. Strong Shuriken upgrades by four damage.
- Oyeah Throw Sword consumes the old stock before replenishing. Blade Cycle
  fires all stock and loses three (one upgraded); repeated applications retain
  the lower loss. The previous per-chain token-generation state was deleted.
- Current rewards contain 20 common, 35 uncommon and 25 rare cards, ordered by
  the edited board through the native pool property. There are 92 current card
  models. The retired second placeholder is local reference only.
- Starter relic breathes three without Retain. The ancient relic still creates
  two retained Chado and breathes two. Its exact Chinese wording is retained.
  The unused `retainGeneratedCard` command parameter was removed.
- Native draw, discard, exhaust, transform, temporary retention, Thorns and
  hand-capacity handling remain the owners of those operations. Previous boss
  reload/greeting, exhaust UI, tooltip and event text fixes remain in place.

## Verification and evidence

`NinjaSlayer.OrbContractTests` checks both base and upgraded metadata for all
92 cards, the actual reward sequence, bilingual formatting, native discard/Sly
choices, status cards, Chado, opening relics, damage-source filtering, temporary
stats, orb lifecycle, per-shot conversion, full-hand overflow, snapshots,
native damage mitigation, no healing and exactly one death for a lethal hit.
The RitsuLib contracts check required-patch rollback and the existing animation
ownership boundaries. ENet contracts compare two processes after real native
card actions, including converted tokens and their Focus snapshots.

Windows smoke exercises four speeds of cancelled transform pool reuse, normal
hand transformation/upgrade/exhaust, exhaust badge/list agreement, visible
tooltips, Naraku damage absorption, form and finisher presentation, new runs and
reload. Separate modes cover A10 double-boss reload and complete AutoSlay.
Exact candidate paths, hashes, module MVIDs and actual mod versions are recorded
under `build/v0.2.0`; development evidence using the parent SHA is not final
candidate attestation. The final local report records which modes actually ran.

The first full AutoSlay stopped in a native shop purchase: Orrery waits for its
five rewards while the native shop handler waits for purchase completion.
SmokeDriver now invokes the native overlay drain during that wait. This is a
test-driver change only. The rerun completed successfully using the unchanged
4031f28 product package; both attempts are retained as evidence.

Only stable 0.107.1 is installed as a complete Windows game. Preview 0.111.0
managed inputs are available for builds, contracts and ENet, with stable assets
used for those contracts. This is not preview rendered gameplay evidence.

The browser URL security policy refused the local v1.6 HTML page. No alternate
browser or indirect navigation is used to bypass it. Embedded data, IDs,
counts, notes and JavaScript syntax can be checked locally; interactive editing,
dragging and download/reopen acceptance remain explicitly unverified here.

Old running saves remain unsupported. Unsupported-model reads must preserve
the original file; no historical model migration or compatibility registry was
added. Both Workshop change-note files contain the same local draft.
