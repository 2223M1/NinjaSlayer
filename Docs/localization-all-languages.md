# 全語言本地化

## 範圍

模組保留既有簡中、英文與日文定稿，新增繁中、德文、拉美西班牙文、法文、印尼文、義大利文、韓文、波蘭文、巴西葡萄牙文、俄文、歐洲西班牙文、泰文與土耳其文。

目前穩定宿主 0.107.1 原生有 14 個語言選項，預覽宿主 0.111.0 有 16 個（多出 ind / zht）；Steam 商店的 14 語清單不包含這兩個。模組資源與網站一併提供 16 語。每語 17 表、620 鍵，網站每語 271 個介面文案。

卡牌、遺物、能力沿用對應宿主原版術語與短句效果格式，包括條件、時點、全體/隨機目標、次數、生命損失與傷害的區別。兩套西語不混用詞彙。波蘭語/俄語保留原版多分支複數規則，俄語使用 `plural(ru)`。網站數字槽、SmartFormat 變數、`diff()/energyIcons()/show`、富文字標記與刻意空串不翻譯；先古 `Both` 是控制值。

人物、忍術專名與敘事以已審定的模組中/英/日文本為準。Domo、-san、desu、奈落內在聲音、南希的老搭檔語气沿用現有考據（見 `Docs/localization-ja.md`、`Docs/lore/`）。塔內事件是模組創作補全，不宣稱為小說原文；新增語言譯名不宣稱為官方忍殺譯本。沒有新增故事事實、模型ID或玩法，也未改卡牌參考表的原有中文/英文規格。

新增外語由分組代理逐條起草/復核；不採用前次失敗的機器譯稿。繁中由簡中定稿離線轉換後逐表核對原版術語、臺灣用詞與變數。未做第三方母語者認證或全部語言的真實遊戲卡面視覺審查。

## 驗證

- `node tools/validate-localization.mjs`：16 語、17 表、620 鍵，變數與 formatter、標記及控制值檢查。
- `node tools/sync-website-localization.mjs --check`：16 語網站文案與编号槽，生成模組與 `Website/i18n/*.json` 一致。
- `tools/localization/Test-AllLanguages.ps1`：掛載每個宿主的精確版本原版 localization，再掛載本輪新匯出的模組 PCK；離線 Godot 使用已發布 1.0.15 原 DLL（驗證 MVID/SHA）。不寫入日常遊戲或存檔。
- 預覽：16 語，每語全部 620 鍵，93 張模組卡/185 個基礎及升級狀態，88 個能力键各測數量 1/2/5；全圖目錄 689 張卡、1671 模型。
- 穩定：14 原生語同等文字檢查，671 張卡、1630 模型，無圖。完整穩定版圖像與真實客戶端驗證 **NOT RUN**。不宣稱穩定宿主可在選單選 ind / zht。

離線導出器需原版 AtlasResourceLoader 與圖集初始化；切語言時清理原版快取的 tooltip 與動態變數，避免附魔名稱混語。這些設定只用於跨語導出，不改玩家的遊戲資料。

## 網站與歷史資料

網站介面與當前 1.0.15 卡牌資料提供16語，語言選擇儲存於 URL / 本機偏好。玩家來信、作者回覆等使用者資料不自動翻譯。資料統計、版本、數值、費用、稀有度、類型及關鍵字不變。

`Website/content/versions/` 與發布指紋保持不可變；新增翻譯寫在 `Website/content/localization/1.0.15/<lang>.json`，記錄基準 DLL/源提交/發布指紋及翻譯源稿 SHA。歷史版本沒有該語資料時明示使用英文，不偽造歷史翻譯。網站僅發布翻譯，補充目錄沿用歷史圖片。

基準英文目錄有三項原版附魔名稱的舊跨語快取（PAELS_CLAW、PAELS_GROWTH、ROYAL_STAMP），新導出修正為 Goopy/Clone/Royally Approved。三項圖片讀回雜湊不同（ADAPT、NAVY_HAMMER、YUMMY_COOKIE）；歷史基準均不覆寫，補充目錄保留原圖。導入器只接受這些已定位差異，拒絕其他原版規則、文字或圖片变化。

官網發布沿用 GitHub Pages/既有 PR 與 CI 保護。本輪沒有更新創意工坊、遊戲版本或已有已發布套件；新增本地化源稿和驗證 PCK供下一次遊戲發布整合。
